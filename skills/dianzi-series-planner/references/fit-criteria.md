# 风格契合判据

通用评级顺序（三否决 → 契合 → 六力 → 定星）见 `h3-research-director/references/planning-method.md` 第五节；这里只写本风格专有的。

- 基线：风格 skill `dianzi-style-explainer` 有哲学（7 条）、主配方、三层表、作者感觉、hit-mechanics——见风格 skill 对应节，这里不复制。

## 选题门（由哲学导出）

| 门 | 问 | 来自 | 过的例子 | 不过的例子 |
|---|---|---|---|---|
| G1 能先做一次吗 | 有没有一个观众能当场预测 / 估计 / 自读 / 比较的入口？ | P1 | "床前明月＿"；三扇门换不换；两条线哪条长 | 某次战役的经过；化学反应方程 |
| G2 形式即内容吗 | 能不能让观众身上发生本期讲的那件事（至少一处）？ | P4 | 讲冗余就让他读乱序句；讲注意就让他漏看 | 讲"量子纠缠"（观众无法经历） |
| G3 有共同经验吗 | 能不能找到 ≥2 个不用解释的日常例子放在公式前？ | P5 | 输入法联想、抢红包、排队 | 只在实验室出现的现象 |
| G4 能交还吗 | 结尾能不能留一个只有观众能完成的问题或动作？ | P7 | "打开输入法打'我想'"；"找朋友玩一次三扇门" | 纯结论型（"所以 X 等于 Y"） |

G1 或 G2 不过 → 不是本风格的题。G3、G4 不过 → 降一星。

## 契合问题（三层表本质改写，1–5 分）

| # | 本质 | 问 | 5 分 | 1–2 分 |
|---|---|---|---|---|
| F1 | 画面：有被观众操作的对象 | 这个题能不能给出一个屏上的"实验材料"（残句、数轴、卡片、图形）？ | 材料本身就是知识（乱序句之于冗余） | 只有示意图 |
| F2 | 画面：观众的状态被画出来 | 观众脑子里的状态能不能画成仪表？ | 有天然读数（概率、剩余可能、bits、你的票） | 状态只能用旁白描述 |
| F3 | 画面：揭晓 = 变亮 | 答案能不能落在"某处亮起来"上？ | 有一个明确的答案位置 | 答案是一段解释 |
| F4 | 节奏：出题 → 留白 → 揭晓 | 能不能拆出 ≥3 个"出题—揭晓"？ | 4–6 个，每章一个 | 只有 1 个 |
| F5 | 节奏：最大翻转前最安静 | 有没有一个足够大的翻转？ | 翻"观众以为没用的东西" | 无翻转 |
| F6 | 文字：体验 → 命名 | 每个术语前能不能先给体验？ | 全部能 | 术语就是入口 |
| F7 | 文字：题必中或答不出即答案 | 题目会不会让观众觉得自己笨？ | 答错天经地义（直觉陷阱） | 有标准答案的考试题 |
| F8 | 声音：过程即声音 | 过程有没有自己的声音（打字、计数、噪声）？ | 有 | 只能配乐 |

平均 ≥4 且 F1、F2、F7 都 ≥4 才可能五星。

## 六力检验问题（本风格改写）

- 钩子：第一帧的实验，观众 1 秒内能不能"做成"一次？
- 获得感：看完能不能拿去考别人？
- 大众度：实验材料是不是人人都懂（诗、生活物、手机）？
- 情绪：有没有"我居然也会错"的那一下？
- 社交货币：评论区能不能"填空 / 晒答案"？
- 系列化：同一个仪表 / 母题能不能贯穿 ≥10 期？
力的名字和星级线不改。

## 专有否决

- 必须真人表演或真人视频才能成立的实验（经典"看不见的猩猩"原视频）→ 改成自制几何实验，改不了就否决。
- 依赖精确颜色 / 精确时长显示的实验（残像、闪烁频率）→ 只能代码层做，H3 不碰；代码层做不到就否决。
- 自测会被理解为诊断（视力、色觉、心理测评打分）→ 合规否决；只讲现象。
- 投资 / 医疗结论 → 合规否决；只讲直觉。
