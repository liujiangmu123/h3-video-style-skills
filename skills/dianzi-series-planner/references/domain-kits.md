# 领域套件（每个立项方向一节；不写 hex）

## A · AI 只做一件事
- 舞台物：发光残句 + 金色空格（贯穿）；候选词竖列；词表格子墙；温度刻度条；向前延伸的字链。
- 原子素材：一个空格。
- 仪表：置信度条（金色横条长度 = 概率；数字代码层）。
- 共同经验：输入法联想、键盘下一个词、歌词 / 成语接龙。
- 证物阶梯：古诗填空 → 输入法 → 自动补全 → 对话式 AI（全部画成抽象界面，不画 logo）。
- 钩子：填空（必中 / 必不中）、"它也会错"。
- 画布与强调色：沿用作者默认——近黑 + 金；理由：答案 = 概率最高的词亮起来。

## B · 你的大脑被骗了
- 舞台物：错觉图形（代码层精确画）；记忆格子；注意力光圈；"你的答案 vs 真实"两根并排条；空框（镜子，交还用）。
- 原子素材：两条线 / 一个格子。
- 仪表：你的答案 vs 真实。
- 共同经验：看错路牌、忘钥匙、排队、刷手机。
- 证物阶梯：图形错觉 → 生活场景 → 经典实验（只给年份与出处，不讲故事）。
- 钩子：你一定会看错 / 记错。
- 画布：近黑 + 金；理由：错觉材料在暗底上对比最清楚。

## C · 直觉投票站
- 舞台物：投票槽（金框）；"你的票"发光块；模拟小格墙（一格一次试验）；收敛折线。
- 原子素材：一张票。
- 仪表：你的票 vs 一万次模拟。
- 共同经验：抽奖、抢红包、检测报告、排行榜。
- 证物阶梯：游戏 → 生活 → 真实数据案例（来源必注）。
- 钩子：投一票（必错的直觉题）。
- 画布：近黑 + 金；暗红只给"你的票错了"之外的被排除项，不给观众的票（不羞辱投票的人）。
