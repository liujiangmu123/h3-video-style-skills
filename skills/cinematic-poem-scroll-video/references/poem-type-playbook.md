# 题材手册与美感方法论（任何诗词 → 标杆级美感）

本手册回答一个问题：换任何一首诗词，如何生成《望海潮》标杆那种美感。使用顺序：先做题材定调（第四节），再逐句设计画面并过美感七要素（第一节）与翻译五规则（第二节），最后用第五节的词库落笔英文。

## 一、美感七要素（每镜逐项核对）

美的镜头七项全有，平庸镜头至少缺三项。这是 style-dna"美感四查"的完整展开：

| 要素 | 规则 | 英文落笔示例 |
| --- | --- | --- |
| 光 | 每镜的光必须"做一件事"：逆光勾轮廓/体积光穿雾/灯火流动在材质上/晨雾漫射。平顺光=素材感 | `golden backlit haze`, `god rays through mist`, `lantern glow rippling on lacquer`, `rim light tracing the silhouettes` |
| 色 | 受限色板+单一锚点色（style-dna A3/B2）：冷底必有一处高饱和文明仪式色（华夏语境默认红系），暖底要有一处冷压秤 | `a streaming red signal flag against the grey-green water` |
| 层 | 前景遮挡包画框 + 远景永远含雾（大气透视=古画感来源） | `dark eaves framing the top corners`, `layered mist bands`, `atmospheric perspective` |
| 人 | 人物是尺度与情绪入口：渺小人物给奇观比例，背影是观众替身；密度镜与孤独镜交替 | `a tiny robed figure dwarfed by...`, `with her back to the camera` |
| 势 | 构图能量对应句子语气：对称一点透视=威仪；对角线=动势；大留白=诗意；留意诗句自带的几何指令（孤烟直=垂直线，落日圆=正圆） | `in strict one-point perspective`, `rising perfectly vertical`, `a perfect circle touching the water` |
| 质 | 每镜至少一种"会接光的材质"：绸缎/水面/漆器/青铜/雨珠/纱幔/鎏金 | `rippling silk`, `rain-beaded lattice`, `polished lacquer`, `bronze cups` |
| 动 | 每镜只装一个动作事件（1.3-3 秒只够一件事），运镜参与动词而非旁观 | `an enormous bolt of white silk unfurling`, `tracks backward just ahead of the advancing wave` |

## 二、意象翻译五规则（诗句 → 画面）

1. **名词句 → 装置化**：不是"拍到它"，而是"让它表演"。罗绮 → 横空翻卷过屋顶的白绸；珠玑 → 被一只手提进灯光里的珠串。
2. **抽象句 → 可拍代理物**：豪奢 → 灯宴金光+舞袖剪影；清嘉 → 晨雾双湖+塔尖初光。找"一看就懂"的代理物。
3. **动词句 → 动作奇观+运镜配合**：怒涛卷霜雪 → 浪墙推进+镜头在浪前倒退跟拍。运镜要参与动词。
4. **情感句 → 落到身体上**：多情应笑我 → 摇头苦笑、风扯衣袍；嬉嬉 → 溅起的水花、弯着的钓竿。不拍情绪，拍身体。
5. **数字夸张句 → 重复元素密度**：十万人家 → 屋顶海洋；千骑 → 旗林人马阵列；十里荷花 → 荷叶铺到雾中地平线。数字=同一元素重复到看不见边。

## 三、全片级美感（比单镜更重要）

- **母题贯穿**：开工前选定 1-2 个签名母题（望海潮="红×水"；念奴娇="水×月"；雨霖铃="柳×月"），让它在多个镜头里变奏，末镜做最终变奏（首尾呼应）。
- **密度呼吸**：极密镜之后接极疏镜；留白镜是被前后的密度"挣"来的，连续两个空镜必然拍平。
- **色彩弧线**：开篇暖调立世界 → 中段冷暖交替呼吸 → 高潮段饱和与密度最高 → 末镜互补色平衡定格（如红殿+青水）。
- **记忆点镜头**：每片指定 1-2 个"能被截图传播"的装置镜头（对标白绸横空、巨卷横殿），用双倍措辞密度去写。
- **节奏与题材匹配**：豪放/都会 1.8-2.0 秒/句；婉约放慢到 2.2-2.6 秒/句；末句一律加长定格。

## 四、六类题材手册

### 1. 都会繁华（望海潮、青玉案·元夕、木兰花慢）
- 优势：密度天然高。风险：杂乱。
- 策略：直接套标杆配方；用前景框收束杂乱；元夕类的烟花灯树是天然记忆点。
- 色板：暖金主导+红灯笼/红桥；配乐走标杆四阶段。

### 2. 豪放怀古（念奴娇、永遇乐、满江红、南乡子）
- 优势：气势。风险：冷空镜连发、灰平。
- 策略：**今昔双线冷暖编码**——现实线冷青灰，回忆/用典线整体转暖金人间戏（宴、婚、军阵、火攻）；"人道是/遥想/笑我"等叙述句全部落到具体人物；火、旗、甲胄、印做红点；自然奇观镜必加渺小人物。
- 配乐：现实段弦乐长音+古琴，回忆段进鼓与全奏，收尾撤鼓留泛音。

### 3. 边塞征戍（使至塞上、凉州词、燕歌行、渔家傲·塞下秋来）
- 优势：大漠金光、地平线极简天然美。风险：单调。
- 策略：抓诗句自带的几何指令（孤烟直=垂直线、落日圆=正圆、长河=蜿蜒对角线）；驼队、旌旗、烽燧、戍卒做人迹；红缨红旗点睛；日夜与沙雪对比做色彩节奏。
- 配乐：加入胡笳/马头琴式拉弦质感+低鼓，避免江南丝竹。

### 4. 婉约离愁（雨霖铃、声声慢、一剪梅、鹊桥仙）
- 核心：**尺度反转**——美感来自"小与近"而非"大与远"。
- 策略：以特写与中近景为主；室内烛光、雨窗、残酒、湿袖等接光小材质；**冷蓝底+一点将熄的暖光**（残烛/孤灯/灯笼）是标准色板；前景层用雨珠窗棂、垂柳丝、纱帐；动作要轻（烛焰一晃、柳丝一拂、泪未落）；留白比例全类型最高。
- 节奏：2.2-2.6 秒/句；配乐撤掉鼓组，古琴+箫+雨声环境；朗诵可换清冷女声（用户不指定时仍默认男声）。

### 5. 山水田园（山居秋暝、饮酒、渔歌子、过故人庄）
- 优势：干净。风险：变成无人风光片。
- 策略：必须注入烟火人迹——炊烟、柴门、浣女、渔舟、牧童；晨昏漫射光；环境声（水、竹、鸟、桨）在 soundscape 里加重份量；密度呼吸靠"空山—人迹"交替。

### 6. 咏物言志（卜算子·咏梅、石灰吟、竹石）
- 风险：单主体重复。
- 策略：同一主体在不同光线、景别、天气、季节中变奏（微距摄影感：`macro close-up`, `frost crystals`, `petal veins backlit`）；用光的变化做节奏；结尾把主体放进大环境完成"言志"升格。

## 五、可靠产出美感的英文词库

- 光：`golden backlit haze` / `god rays through mist` / `rim light` / `volumetric morning light` / `lantern glow rippling on lacquer` / `a dying ember of lamplight`
- 空气：`atmospheric perspective` / `layered mist bands` / `drifting cooking smoke` / `dust glowing in the backlight`
- 材质：`rippling silk` / `rain-beaded lattice` / `polished lacquer` / `bronze` / `gauze curtains` / `molten-gold water`
- 密度：`an ocean of grey-tiled rooftops` / `a forest of red banners` / `crowds flowing between timber shopfronts` / `lotus leaves stretching to the misty horizon`
- 几何：`in strict one-point perspective` / `rising perfectly vertical` / `a perfect circle touching the water` / `mirrored ranks on both sides`
- 尺度：`tiny against the...` / `dwarfed by...` / `reduced to a small figure beneath the immense sky`
- 颜值（人物必须理想化）：男 `strikingly handsome, sharp jawline, sword-straight brows, clear dark eyes`；女 `breathtakingly beautiful, porcelain skin, willow-leaf brows, lips a dot of vermilion, an ethereal grace`；老者 `silver-haired elder with an immortal's serene grace`；配人像光 `soft side key light, rim light tracing the profile`

**禁用裸形容词**：beautiful / stunning / epic / breathtaking 单独形容**画面或环境**无效——模型对形容词免疫，对"名词+光+材质+正在发生的一件事"敏感。写"美"无效，写"什么材质在什么光里正在做什么"才有效。唯一例外是**人物颜值**：形容词必须与具体五官特征成对出现（`strikingly handsome` + `sharp jawline...`），单写形容词或单写五官都不稳定。

## 六、美感进阶（镜内调度与光学质感）

在七要素之上再加七条，用于把"好看的画"升级成"活着的电影"：

1. **镜内三层运动视差**：前景、中景、远景各安排一个不同速度的运动（前景柳丝慢摆 / 中景人物动作 / 远景雁阵横渡），静止镜头也因此有纵深呼吸。英文：`foreground willow strands drifting slowly, ... in the middle ground, while a line of geese crosses the far sky`。
2. **光要"发生事件"**：光不是状态而是事件——烛焰被风压低再直起、云破月出、灯次第亮起、涟漪把倒影揉碎再拼回。每组至少一次"光的事件"。
3. **每镜一个微物理细节**：泪珠落在手背、墨滴在纤维里晕开、酒面映着灯焰微颤、蒸汽从茶炉盘旋——微物理是"贵价感"的直接来源。
4. **动作中段进入**：人物入镜时动作"已经在进行中"（`already mid-stride`, `the gesture already underway`），避免 AI 生成常见的"起手式僵直"。
5. **光学质感词（谨慎、每镜至多一个）**：`soft halation around the lantern flame`（灯月光晕）、`compressed telephoto perspective`（大远景长焦压缩）、`shallow depth of field`（婉约特写）、`gentle film grain`（全片统一时写进风格句而非逐镜）。
6. **声画错位卡点（J-cut）**：切点比语音起点提前 0.2-0.4 秒，画面先到、词后至；名场面句提前量最大，让观众"先看见、再听懂"。
7. **静镜不死静**：所有 static shot 必须注明一个持续微动（`the frame breathing with drifting mist`、灯焰摇、水面微漾），H3 的静止镜头才不会冻结。
8. **大留白镜**：每组安排一个"负空间大画面"——巨大的天空/水面/黑暗，其中只有一点光源或一个微小主体（黑蓝夜江上一扇烛光小窗）。它既是密度呼吸的"呼"，也是最容易出高级感的镜头。
9. **信息瘦身**：删掉互相竞争的细节，每镜微物理细节 ≤2 个、视觉从句 ≤3 个。模型的美感预算有限：写十样东西=十样平庸，写三样=三样精致。单镜的美来自"一幅画画透"，不来自堆料。

## 七、气质光谱与"恢弘注入"配方

回答一个高频问题：暖色、恢弘、"长安大气"的感觉是否只有《望海潮》这类都会繁华题材才能产生？——**不是**。恢弘是处理方式，不是题材属性。它由四个杠杆合成，题材只决定杠杆的"天然供给量"，供给不足可以人为注入。

### 7.1 恢弘四杠杆

| 杠杆 | 内容 | 英文触发词 |
| --- | --- | --- |
| 尺度 | 巨构建筑/自然奇观 + 渺小人物对比 | `colossal gate towers`, `tiny figures dwarfed by...` |
| 密度 | 万人、千帆、旗林、灯海、檐瓦海洋 | `an ocean of...`, `a forest of...`, `thousands of...` |
| 暖金光 | 金色时刻 + 炊烟尘埃体积光 | `golden-hour haze`, `god rays`, `dust glowing in the backlight` |
| 威仪 | 中轴对称 + 一点透视 + 缓推 | `in strict one-point perspective`, `slow push down the central axis` |

四杠杆全开=盛世恢弘（《望海潮》）。恢弘分两种温度：**暖恢弘=盛世感**（朱红+鎏金+灯火+金尘，即"长安大气"），**冷恢弘=苍茫感**（雪原铁骑、月下宫阙、冰封大江）。用户说"大气"默认取暖恢弘，边塞怀古可取冷恢弘。

### 7.2 注入规则

1. **每首诗先定主气质**：壮美（恢弘）/ 优美（唯美）/ 清逸 / 苍凉 / 绮丽。主气质决定全片基调，恢弘作为可调注入量。
2. **非恢弘诗也可注入恢弘段**，位置限三处：开篇立世界、情绪高潮、收尾大定格；婉约诗至多用 1-2 处。依据是诗中任何指向城市/江山/天地的词（"都门"→汴京城门千帆，"举头望明月"→长安全城月色俯瞰）。
3. **对比让恢弘更恢弘**：小景之后的大景比连续大景更震撼；全程恢弘会麻木（原片把"天堑无涯"的空旷镜夹在高密度镜之间，就是在造对比）。
4. **恢弘 + 唯美的合体公式**：恢弘大景里放一个超级唯美的人物锚点——灯海中回眸的美人、宫阙前独立的白衣公子（《长恨歌》《青玉案·元夕》型）。大与美互相成就，这是"暖色恢弘 + 超级唯美"的标准解。

### 7.3 盛唐长安视觉包（环境套件，可直接调用）

朱红宫墙与鎏金琉璃瓦、含元殿式白石高台阶、飞檐斗拱的落日剪影、宽阔御道与上元灯海、雪落红墙、宫灯长廊、城门旗阵与开门金光、万家灯火的坊市大俯瞰。任何需要"长安大气"的诗（不限唐诗），从此包中取 2-3 件做恢弘注入段即可。
