# 风格 DNA：电影感古诗词逐句大片 —— 两栏结构（常量栏 / 生成规则栏）

逆向自标杆视频：柳永《望海潮》可视化（1932×1080 ≈ 1.79:1 内含上下黑边、宽银幕观感，30fps，43.90s，22 个剪辑点 = 23 镜，mean volume -14.5 dB / max -0.0 dB 影院级响度）。23 个句读与 23 个镜头一一对应，平均 1.9 秒/镜，最短 1.33s，末镜 3.17s。

**本文件结构**：Part A 常量栏＝跨题材不变的电影语法与约束数值；Part B 生成规则栏＝每个变量的推导公式。**规则里不写死颜色**：标杆片的"暖金琥珀/冷青蓝灰"双色板与"朱红点睛"是宋代江南这个世界跑推导后的结果——**冷暖来自光源物理，锚点色来自文明的仪式色**；换一个世界就重推一遍，定律本身不变。

# 主配方 THE FORMULA（全文件的纲；哲学＝这条可复述的主线）

> **一句文本＝一镜（句读即切点，默认直切）→ 每镜一幅超写实的题材世界画面，过美感四查（光质/色彩锚点/人迹/前景装置）→ 冷暖按段落块状交替（暖启—冷张—暖收）→ 记忆点装置＋盛大定格收尾；双色板与锚点色按题材世界的光源物理与文明仪式色推导。**

配方的开放槽位＝扩展入口：文本槽（凡可句读的短句文本——公版诗词/自撰文案/歌词/世界观独白）×世界槽（凡有光源物理与文明仪式色的世界）×收尾装置族（元视角/对称定格/同框彩蛋）。Part A 各节是这条配方各环节的**执行标准**（量化验收值）；Part B 是"按题材世界分配"的**推导公式**。任何一节都不得凌驾于配方之上——细则为配方服务，配方指导一切新世界开工。

# PART A — 常量栏（配方各环节的执行标准：哲学规则 + 约束数值）

## A0. 通用法则取舍表（本风格在行业通识尺子上的读数；尺子本体见 `style-foundations` 技能）

风格＝在通用尺子上的一组特定读数与取舍。本风格是实拍电影逻辑：动画 12 法则大多不适用，运动语法走电影尺子（运镜/剪辑/调度）：

| 通识（尺子） | 态度 | 本风格的形态 |
| --- | --- | --- |
| 迪士尼 12 法则 | 大多不适用 | 实拍逻辑；改用电影运动语法（motion-rulers 第四节） |
| 动接动 / mid-action | 采纳 | 切入时动作已在进行中，切点落在动作行进中（A10.3） |
| 轴线与方向轴 | 采纳 | 全片统一叙事方向，禁跳轴（transition-grammar） |
| 三层运动视差 | 弱化采纳 | 空气层永动＋一次缓推/缓移为主，主体动作可选（实测运动帧仅 28%，A10.2） |
| 三分法 vs 中心构图 | 场景化分配 | 仪式镜用严格中轴对称＋一点透视，叙事镜自由（A4.2） |
| 镜长节奏 | 句读驱动改造 | 节拍器是旁白句读不是音乐：切点＝句读，平均 1.9s/镜（A10.1） |
| 剪辑转场 | 修辞归零 | 22 切中 21 个直切，零叠化零黑场；每 5–8 镜至多一次前景遮挡软标点（A10.6） |
| 冷暖交替 | 采纳且块状化 | 暖启—冷张—暖收，中段 1–2 镜一翻，同温 3 连只给结构段落（A2） |
| 框中框 | 采纳 | 船篷/檐角/雨帘前景遮挡，遮挡物取自题材世界（A4.1） |
| 大气层 | 制度化 | 每镜必有霾/雾/水汽，远景永不清透（A1） |
| 响度气质 | 影院级 | mean ≈ -14 dB 满响度，峰值贴 0（A7） |

发明（通识里没有的作者装置）：美感四查、冷清题材补偿规则、创作者元视角收尾、末镜互补色对定格、颜值强制理想化、字幕即诗句原文无标点。

## A1. 总体影像气质

- **超写实电影感**：实拍质感的古代世界，大规模建筑群、群众场面、自然奇观；
- **空气感**：每个镜头都有霾/雾/水汽/炊烟/尘埃层（atmospheric haze, mist, drifting smoke），远景永远不是清透的；
- **光线哲学**：光必须"有来源、有事件"——大量逆光与侧逆光；金色时刻与阴天冷光交替；体积光（god rays）用于殿堂与雨景；
- **宽银幕**：letterboxed widescreen 观感，构图利用横向延展。

## A2. 色温交替定律（节奏引擎）

- 全片由**一暖一冷两套色调**轮流承担镜头组；冷暖不是滤镜，而是**光源物理的结果**（什么光源、什么天气、什么水汽——见 B1 推导）。
- 标杆实测序列（W 暖 / C 冷 / M 冷底暖点，镜 1→23）：`W W W C W W C C C W W M C W C M C W M M W W W`——暖 12、冷 11（含 4 个 M），整体是**暖启—冷张—暖收**的环形结构。
- 规则＝**按段落语义块状交替**：开篇暖块立世界（标杆镜 1–3）；奇观/张力段冷块约 3 镜（标杆镜 7–9 自然天堑）；其余中段每 1–2 镜翻转一次；高潮用冷底＋红/烛对撞（标杆镜 19–20）；收束暖块 3 镜（标杆镜 21–23）；末镜用一对互补色定格（见 B3）。
- 约束：同温 3 连只允许出现在上述结构段落（开篇/奇观张力段/收束）；同温连排超过 3 镜，或在普通中段出现 3 连＝节奏塌。

## A3. 色彩锚点定律

- **冷底镜必有一处高饱和暖色锚点**——取画面文明最具仪式感的器物色（见 B2）；**暖底镜必有一处冷色压秤**。
- 整镜同温无锚点＝灰片（判定标准，四查第 2 查）。
- 锚点必须是"画面里的东西"（旗、灯、印、袍、漆器），不是调色参数。

## A4. 构图装置库（已验证的六式）

1. **前景遮挡取景**：用船篷拱形内沿、屋檐翘角、垂落的雨帘/纱帘包住画框边缘，形成天然暗角（标杆开篇：船篷下望向红桥城市）；
2. **对称 + 一点透视**：仪仗、城门大道、大殿内景用严格中轴对称，人流与旗阵沿透视线收束（标杆"千骑拥高牙"：城门楼正中，高牙大旗立于画面中轴）；
3. **体量对比**：微小人物 vs 巨物——巨樟树干间牵行的白马、屋顶海洋上一个晾绸的身影、大殿长卷前的一个坐姿；
4. **逆光剪影**：夕照湖面/烟霞中的人物压成暗剪影，轮廓光勾边；
5. **高空俯瞰**：无人机式航拍越过湖面、屋顶群、堤岸；
6. **锚点点睛**：大基底（灰瓦/青水/白雾）上永远有一处 A3 的仪式色锚点（标杆样例：红桥、红斗篷、红灯笼、红旗阵、红柱）。

## A5. 人物与美术

- 锚点人物着题材世界的正装（标杆世界：汉服/宋制——襦裙、褙子、大氅、幞头官服），**多用背影、侧影与远景**，正脸特写少而克制；
- **颜值标准（强制）**：所有出镜人物一律理想化——男性英挺俊朗（`strikingly handsome, sharp jawline, sword-straight brows, clear dark eyes, tall upright bearing`），女性超级唯美（`breathtakingly beautiful, porcelain skin, delicate features, willow-leaf brows, lips a dot of vermilion, an ethereal otherworldly grace`），老者仙风道骨（`silver-haired elder with an immortal's serene grace`），孩童灵秀；**禁用** weathered / wrinkled / plain / ugly 类措辞（用户明确要求沧桑感时除外）；群演也写 `graceful figures in flowing hanfu`；
- **人像光（露脸镜强制）**：出正脸/侧脸时配人像光——柔侧光塑形 + 轮廓光勾边（`soft side key light, rim light tracing the profile`），鬓发与衣袂要接光、有风感（`stray hair and sleeves lifted by the breeze`）；避免顶光死影；
- **环境必美（强制）**：每个场景做一次"美化过档"——花木、灯火、雾气、倒影至少其一；荒凉场景也要"美的荒凉"（霜白芦苇、镜面黑水、雪覆枯枝），禁止 muddy / 杂乱 / 平淡的环境描述；
- 每镜可以换不同人物，不需要跨镜一致（除非用户点名主角贯穿）；
- 群众场面要给到"密度"：市集人流、桥上行人、码头船工、围观人群；
- 建筑与道具从题材世界取（标杆世界：宋式木构、重檐、回廊、白石栏杆、灰瓦连绵；折扇、油纸伞、茶炉、横笛、长卷、印章、绸缎、灯笼）；
- **所有人物永不开口说话**（朗诵是画外音，口型闭合）。

## A6. 字幕规格

- 每镜一条，内容为该镜对应的诗句原文，**无标点**；
- 白色衬线字体（宋体/楷体气质，serif），带轻微软阴影，居中排在画面下方安全区；
- 英文措辞模板：`the phrase "烟柳画桥" appears in white serif typeface with a soft shadow, centered near the bottom of the frame`；
- **字幕跟语音、不跟画面**（标杆实测）：字幕随朗诵起点进入（先于语音 0–0.2s），因为"先切画、后开口"，通常比切点晚 0.1–0.5s 出现；J-cut 镜（声先入画，标杆镜 2→3）字幕随声先于切点出现；句尾可随语音先退，镜尾留纯画面；段落衔接处允许一次字幕 L-cut 跨切黏合语义（标杆："异日图将好景"字幕跨过 40.733s 切点在大殿镜内留约 0.3s）。不叠不闪。

## A7. 声音设计

- **朗诵（画外音）**：深沉浑厚的中年男声，庄重的吟诵语速，带殿堂混响；每镜恰好一句，按"先切画、后开口"对位（切点先于语音均值 ≈0.25s，见 A10.1）；H3 写法固定为 `says in an off-screen voiceover` + `<d>[Chinese] 诗句。</d>` + 口型闭合声明；
- **配乐四阶段结构（常量）**——乐器族按题材世界推导（B4），结构与走向不变：
  1. 铺垫（开篇组）：低音长音 + 单音点缀，慢速；
  2. 发展（意象组）：加入旋律线与轻打击，中速推进；
  3. 高潮（仪仗宴乐组）：重鼓 + 全奏 + 涌动式渐强，力度层层加强；
  4. 收束（作画/大殿组）：鼓退场，回到长音与泛音，尾音悬停；
- **环境声（overall_soundscape）**：按镜头组配——水声桨声、市集人声嗡鸣、马蹄与旗帜猎猎、雨打瓦檐、绸缎破风、殿堂空间残响；
- 成片响度对标影院级（mean ≈ -14 dB，峰值贴 0 dB）。

## A8. 收尾装置（格式常量；括号内为标杆样例）

- **倒数第二镜｜创作者元视角**：高处室内，一位创作者正在把全片世界收进一件作品里（标杆：高阁内白袍画师绘制长卷，卷起的竹帘做上缘前景，窗外是全片出现过的湖山全景）；可选彩蛋——远景古今同框（现代天际线隐现，暗示"好景"延续千年）；
- **末镜｜盛大对称定格**：中轴对称的大空间开向 B3 推导的互补色景观，主角居中、两侧对称列座，镜头缓推或静止持续到片尾（标杆：红柱大殿开向青绿水面白石拱桥，青绿山水长卷横贯长案展开）。

## A9. 美感引擎：每镜四查（防止"拍平"）

标杆片的美感不是来自题材，而是来自每个镜头都同时满足以下四项。逐句设计画面后，**每镜必须过这四查**，缺任何一项就重新设计：

1. **光质查**：本镜的光有没有被写出来？必须点名一种——golden backlight / god rays through mist / rim light on silhouettes / lantern glow / cold haze with a warm accent。没有光质描述的镜头会生成成"平光素材"。
2. **色彩锚点查**：冷底镜有没有一处高饱和仪式色锚点？暖底镜有没有一处冷色压秤？（锚点色按 B2 推导；整镜同温无锚点 = 灰片。）
3. **人迹查**：画面里要有人物、人群或文明痕迹（建筑、舟楫、绸缎、灯火、石刻、器物）。纯自然空镜每组最多 1 个，且必须夹在人迹镜之间做呼吸；连续两个空镜必然拍平。
4. **前景/装置查**：要么有前景遮挡层（船篷、檐角、雨帘、柳枝、竹帘、旗角）包住画框，要么有一个**人造奇观装置**（白绸横空、巨卷横殿、红氅搭瓦、墨点炸月式的设计动作）。"直接拍风景"不算设计。

**冷清题材补偿规则**：怀古、边塞、山水类诗词（如《念奴娇·赤壁怀古》）意象天然荒寒、少人，直接逐句翻译会得到一串无人冷空镜。此时必须主动补偿：把"人道是/遥想/笑我"这类叙述句全部落到具体人物身上；给自然奇观镜加入渺小人物做体量对比与情绪支点；把回忆/用典段整体转成暖调人间戏（宴、婚、军阵、灯火）；冷镜的锚点用旗、火、灯、印补齐。宁可加一个原文没有的旁观者，也不要连续三个无人空镜。

## A10. 运动与节奏哲学（节奏单位是镜头，镜内永不静止）

本风格的节奏引擎与"单画布连续变形"型风格相反：**节奏由剪辑承担，不由画面内的启停承担**。

1. **句读即剪辑点**：一句文本＝一镜＝一个切点，朗诵的句读就是节拍器。标杆数值：平均 1.9s/镜（最短 1.33s，末镜 3.17s 缓推定格）；镜头时长与配乐反向配合——"音乐强则剪辑稳"：高潮段镜长稳定在 1.90–2.13s，最短镜（1.33–1.53s）落在音乐婉约段，收束末镜拉长。**切点先于语音起点**：23 句中 18 句先切画（多为 0.1–0.35s），均值 ≈0.25s；段落交界拉大（上下片交界 +0.47s），环境声镜更大（雨景 +0.90s，先听雨再开口），冲击镜压到近零（怒涛/竞豪奢/菱歌 +0.03s）；J-cut（声先入画）只在片头镜 2–3。
2. **镜内以一次缓推＋空气层为主**（实测运动帧仅 28%，全是缓推/缓移，无剧烈动作）：① **空气层**：雾、烟、雨、尘、飘絮永动（A1 空气感的运动面，速度最慢、近乎悬浮），这一层冻结就会破坏实拍感；② **主体层（可选）**：诗句自带动词时，焦点人物做一个清晰可读的动作（牵马、展卷、抬眸、挥毫），一镜至多一个；没有就交给空气层与缓推；③ **群众/环境层**：有人群时人流、旗帜、船只、灯火低幅度持续动。本风格里"定格"只存在于末镜的缓推收束。（playbook"三层运动视差"是同一定律的空间投影：前/中/远景各承载一层不同速度。）
3. **Mid-action 入镜**：每镜切入时动作已在进行中（马已在走、绸已在展、雨已在下），不从零起手；切出时动作未完——切点落在动作行进中，镜与镜之间靠"未完成感"缝合，这是电影感的重要来源。
4. **运镜有方向、幅度克制**：每镜一种明确运镜——slow push in / lateral track / aerial glide over / static with atmospheric drift；运镜方向服务构图装置（沿一点透视缓推、越过屋顶海洋横移、绕巨物弧移）。禁止手持晃动、快速变焦、一镜多种组合运镜。
5. **速度分层与配乐同步**：空气层最慢，群众层中速，主体动作可到全速（骏马、泼墨、绸缎破风）；整体速度曲线跟 A7 配乐四阶段走——铺垫慢、发展中、高潮快而密、收束放缓至末镜定格。
6. **转场修辞归零**：标杆 22 切中 21 个为无修饰直切（95%），1 个前景遮挡借势切（镜 6→7，路人掠过遮挡，scene 分数 0.311 为全片最低），**零叠化、零黑场、零光效转场**；注意力管理交给冷暖翻转/景别跳变/动静撞击，一个切口不同时突变三个以上大变量。默认直切；每 5–8 镜至多一次有物理动机的软标点；transition-grammar 七式是扩展层，不是标杆特征。

## A11. 禁忌清单

- 除刻意彩蛋外出现现代元素（电线、现代服装、玻璃幕墙）；
- 人物对口型说话/唱歌；
- 卡通、动漫、水墨渲染等非写实风格词；
- 字幕带标点、字幕缺失或一镜多句；
- 画面内出现水印、署名、logo 文字；
- 配乐描述使用情绪形容词（悲壮、恢弘等）——只写乐器、速度、律动与强弱。

# PART B — 生成规则栏（每个变量的推导公式；标杆值只是样例）

## B1. 双色板推导（冷暖＝光源物理，不是调色偏好）

问两个问题，从题材世界的光源与水汽体系里导出两套色调：

1. **这个世界的"暖"从哪来？**——人造光与金色时刻：夕照、烛光、灯火、炊烟里的金尘。标杆（宋代江南）→ 暖金琥珀；边塞 → 沙金/篝火橙；雪国 → 窗内灯暖。
2. **这个世界的"冷"从哪来？**——天气与水汽：晨雾、雨、月夜、江海。标杆 → 冷青蓝灰；边塞 → 雪青/铁灰；热带 → 雨绿/靛青。

每套色调都要能回答"这是什么光、什么天气"。按题材类型的现成落地见 `poem-type-playbook.md` 第四节。

## B2. 锚点色推导（A3 定律的取色公式）

问：**画面文明最具仪式感的高饱和器物色是什么？** 华夏诗词语境默认朱红系（旗、灯、印、漆、袍、桥）与鎏金；其他世界按其文明重推（游戏世界观 → 其阵营徽色；西域 → 织毯绛红/铜金）。约束：锚点是画面里的实物；一组镜头内锚点器物可换、色系不变。

## B3. 末镜互补对推导

末镜定格用一对互补色制造"最后一眼"的张力——从 B1 的暖套与冷套里各取一件实物级载体（标杆样例：朱红大殿 × 青绿水面长卷）。互补对定格是格式常量，具体色对随世界重推。

## B4. 乐器族推导

配乐四阶段结构（A7）不变，乐器族按题材世界换：华夏诗词 → 古筝/箫/琵琶/大鼓（taiko 式重击）；边塞 → 加胡笳/马头琴族；其他世界 → 其文明的弹拨/吹管/重鼓对应物。禁令不变：只写乐器、速度、律动与强弱，不写情绪词。

## B5. 镜内动作推导（诗句的动词落成主体层动作）

问：**这句诗里谁在动、动什么？** 把诗句自带的动词直接落为该镜的主体层动作（"竞豪奢"→ 绸缎当空展开；"千骑拥高牙"→ 旗阵行进）。诗句无动词（纯意象句）时，从题材世界里补一个符合物性的动作给人迹层（炊烟升、灯笼晃、旗猎猎、舟横渡）——呼应 A9 人迹查与冷清题材补偿规则。约束：一镜至多一个主动作（可以没有，见 A10.2），速度符合 A10.5 的分层（重物慢、轻物快、绸与马可全速）；动作在切入时已在进行中（A10.3）。
