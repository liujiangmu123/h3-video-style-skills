# 阶梯模板 · knowledge-ladder-explainer

写一期前先填完这张卡，填不出的格子说明选题没准备好。

## 选题卡
```
题目：从 <高中工具> 到 <高级概念>
真问题（冷开场一句，第 3 级预告）：
回扣物（开场出现、结尾由观众"点亮"）：
旋钮（全期唯一可拖参数）：
1 直觉：日常现象 ＿＿  观众动作（用眼睛选/估）＿＿
2 工具：高中工具 ＿＿  小胜一次（工具在简单情形下成功的实测数字）＿＿
3 困难：失败的量化画面（误差从 ＿ 到 ＿）＿＿  悬问一句 ＿＿
4 推广：新概念 ＿＿  命名句 ＿＿  溯源一句（人 + 年份）＿＿  必然性一句 ＿＿
5 做出东西 A：手算版（≤3 步）＿＿  代码版（≤40 行，已运行）＿＿  实测结果 ＿＿
5 做出东西 B（迁移应用）：＿＿
三道题：简单 ＿＿ / 动手 ＿＿ / 开放 ＿＿
```

## 时长预算（6 分钟版）
| 段 | 内容 | 秒 |
|---|---|---|
| 冷开场 | 真问题 + 承诺 | 20–25 |
| 1 | 直觉 | 30 |
| 2 | 工具 + 小胜 | 60–80 |
| 3 | 困难 | 40 |
| 4 | 推广 + 命名 + 必然性 | 70–90 |
| 5A | 手算 + 代码 + 实测 | 60–80 |
| 5B | 迁移应用 | 40–50 |
| 收 | 阶梯回看 + 三题 + 回扣物 | 20–30 |

拆上下集时在第 3 级末尾断开：上集以"怎么让它也学会拐弯？"收尾。

## 屏上颜色身份（全线固定）
| 颜色 | 身份 |
|---|---|
| 白 | 真实对象（曲线、门框、山路） |
| 金 #E8B64C | 正确答案、被命名的概念、观众做成的东西 |
| 青 #3FC1C9 | 近似、猜测、工具的输出 |
| 红 #D8382E | 误差、失败（只在第 3 级与必然性前出现） |
| 绿 | 误差达标 |

## 句式库
- 冷开场："你按一下 X，它说 Y。可它只会 Z。它是怎么做到的？"
- 承诺："N 分钟后，你会用 Z，自己把它做出来。"
- 小胜："很准。"（两字，静止）
- 困难："A 只知道 ＿，不知道 ＿。"
- 悬问："怎么让 ＿ 也学会 ＿？"
- 命名："这叫 ＿。"（单独一句，金色大字）
- 溯源："<年份>，<人> 把它写成 ＿。"
- 必然性："因为你要求 ＿，你只能得到这些数。"
- 收尾："你没有背公式，你被一个问题逼着，一级一级爬上来了。"
