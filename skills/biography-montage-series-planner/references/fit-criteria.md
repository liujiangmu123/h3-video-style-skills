# 风格契合判据

通用评级顺序（三否决 → 契合 → 六力 → 定星判定树）见 `h3-research-director/references/planning-method.md` 第五节；这里只写本风格专有的：

- 基线：待填：风格 skill 有哲学 / 主配方 / 三层表 / 作者感觉 / hit-mechanics 就写"见风格 skill 对应节"；没有就按 planning-method 第三节「基线缺件」在这里补（含「口径裁决」，每条注明取自风格 skill 哪一节）
- 选题门：待填：从哲学导出的 2–4 道门（对每条哲学问"什么题材做不到这一条"；深海的四门：原子 / 可演 / 骨架可叠 / 手边），附过 / 不过的例子
- 契合问题：待填：三层表的每条「本质」（画面、画面节奏、旁白、声音都算）改写成一个 1–5 分问题（"这个领域能不能兑现这一条"），附 5 分 / 1–2 分长什么样；作者默认不进契合题
- 六力检验问题：待填：按本风格改写（无旁白 / 短片常见："看完第一句"→"第一帧 + 平台标题"）；不用改就写"沿用通用版"。力的名字和星级线不改
- 专有否决：待填：本风格做不了的素材类型（例：必须实拍、必须真人）
- 已判定不做的方向：待填：方向 | 结论 | 理由（防止重复评估）
