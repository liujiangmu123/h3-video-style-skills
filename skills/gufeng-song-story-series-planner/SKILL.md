# 古风歌曲 · 一歌一故事 · 选题 skill（series-planner）

研发线用：由 `h3-research-director` 第 ④ 步调用。本技能只决定"做什么"（哪首歌配哪段旧事、怎么排季），不写小说、不写提示词（那是风格 skill `gufeng-song-story`；小说笔法在 `xuezhong-style-writing`）。判断一个题合不合适，用的是风格 skill 的哲学：**让一首歌说情绪，从这首歌里找一段本来就有的旧事，用好文字让一个具体的人把它重走一遍；最高的那段先亮，最狠的那句等一次静再落。**

## 方法

六阶流程、三个一票否决、爆火六力、星级判定树、每期字段、撞题、任务消息骨架、合规红线按 `h3-research-director` 的 planning-method 走；完整实例看 `shenhai-series-planner`。本技能只存这条线专有的判据、规则、数据和台账。

## 四元组（每期必须写得出）

**出处（传说 / 史书 / 笔记 / 戏文，公版）× 人（一个具体的人，优先名人身边的小人物）× 回扣物（"那时"和"现在"各出现一次的一件东西或一句话）× 金句（歌里最狠的一句，落在故事的揭示上；古曲换成曲子最强的一段）**。写不全四样的不进库。

## 方向轴与来源

**叙事单元轴**：一期 = 一首古风歌 × 一段本来就有的旧事 × 一篇自己写的小说。本线只有一个主栏目，三个方向是它按出处类型分的子系列，池深按栏目整体算（叙事轴线 ≥100）。

故事从哪来（按这首歌的"来处"找）：
- 歌名是一件物 → 这件物背后的匠人 / 传说（方向01 器物有灵）；
- 歌里有一个地方或一种人（侠、将、女子）→ 史书、笔记、唐传奇里真有的那个人（方向02）；
- 公版古曲 → 曲子本来的故事（方向03）。

候选来源：网易云 / QQ 音乐古风歌单与热评（听众自己补的故事是需求证据）；B 站"原来是真的"一类歌曲考据视频；史书、笔记、唐传奇、元明清戏文目录；地方志与非遗传说。

## 规则（专有，优先于评分）

1. **只做古风**：古风歌只配古代故事，不写现代人、现代职业；说不出"它从这首歌的哪里来"的故事不做。
2. **出处只用公版**，人名、地名、朝代、结局照出处；加工只加在细节和虚构的小人物上，每期样稿列"事实 / 加工"对照，简介写出处。
3. **避开名人大事件**：本库望海潮、唐伯虎、深海已写过大量名人名场面——同一事件让位，同一人物换一件别人没讲过的事，优先写名人身边的小人物（朱家而不是季布的一诺、辩才而不是王羲之、画工而不是昭君）。
4. **歌的版权**：在保护期的歌，发布只走平台曲库站内挂曲（个人、非商用；条款待核）或拿到授权；歌词只引歌名和一两个词，不上屏整段；未授权的歌不混进成片上传。商用只走方向03（公版古曲，自己演奏或 AI 生成录音；AI 音乐商用条款待核，录音有邻接权，不用别人的录音）。
5. 不生成可识别真人，不写在世真人；不用受保护 IP 的人物与情节（如网文里的人物）发布。
