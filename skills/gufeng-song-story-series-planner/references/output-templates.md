# 任务消息（本风格专有部分）

通用骨架见 `h3-research-director` 的 planning-method 第八节。这里补：

- **必读文件**：`gufeng-song-story` 全文与 references（哲学、主配方、产线路线、交付格式、红线必读）；`xuezhong-style-writing`（小说笔法：先笑后走、最重的话最短、名字留到最后）；B 线写整段提示词按 `h3-prompt-writing` 与 `h3-director`「多镜头线出片」；本期借画面的那个风格 skill（默认 `cinematic-poem-scroll-video`）只读它的画面行。
- **锁定参数**：B 多镜头线（模式 A）+ 歌先行时间码（先量这首歌的段落与金句起唱时刻，画面钉绝对时间码）；主推短版约 95 s（小说字约 300 字）与长版整首（400–600 字）；抖音版只给"那时"一眼就懂的题；每期附一版图文（3 张长图约 1000 字）。屏上小说字阅读速度 ≤3.5 字/秒；揭示帧在金句起唱点 −0.25 至 0 s；揭示前 1 小节静；强调色 1 次。
- **每期条目必带**：四元组（出处原文 + 卷次 / 人 / 回扣物 / 金句及其在歌里的时刻）、"事实 / 加工"对照、歌的版本与发布路径（挂曲 / 授权 / 公版录音）、创新档、撞题检查结果。
- **特殊红线**：不图解歌词名词；人物不开口；不加解说、不喊关注；不叠第二条音乐；不改歌词一字；揭示不放在主歌；不写现代故事；史实部分不乱改。
