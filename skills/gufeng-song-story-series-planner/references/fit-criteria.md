# 风格契合判据（古风歌曲 · 一歌一故事）

通用评级顺序见 `h3-research-director` 的 planning-method 第五节；这里只写本风格专有的。

- 基线：风格 skill `gufeng-song-story` 有哲学、主配方、三层表、作者感觉——见风格 skill 对应节，这里不复制。

## 选题门（由哲学导出，任一道不过 = 明显短板）

| 门 | 问 | 过的例子 | 不过的例子 |
|---|---|---|---|
| G0 贴歌 | 说得出"这个故事从这首歌的哪里来"吗（歌名的物 / 歌里的地 / 歌里的典故），找得到一段传说、史书或戏文做底吗？ | 《青花瓷》→ 景德镇窑神童宾；《烟花易冷》→《洛阳伽蓝记》 | 先编好故事再挂一首热歌；古风歌配现代人 |
| G1 具体 | 能配出一个具体的人（或物）和一件看得见的事吗？ | 朱家让戴钳的季布与儿子同桌吃饭 | 只能配出一组意象（月、柳、雁） |
| G2 金句 | 歌里有没有一句能单独当钩子的词（身体记号 / 小数字 / 今昔对照），故事里有没有一个画面能和它对上？ | "相赠眉间一道疤" ↔ 疤的特写 | 全曲没有一句落得到画面上 |
| G3 回扣 | 有没有"那时 / 现在"两层，能用同一构图或同一件物回扣？ | 两只碗、钳痕；看火口诀 | 只有一个时间点 |
| G4 静 | 有没有一个值得停下来的时刻，放得进歌的空拍、长音或间奏？ | "满场肃穆沉默" | 从头到尾都在赶情节 |

G0 不过一律不做（红线：说不出来处的故事不做）。

## 契合题（三层表本质逐条改写，1–5 分）

| 题 | 来自哪条本质 | 问 | 5 分 | 1–2 分 |
|---|---|---|---|---|
| F1 贴歌 | 选题本质 / 哲学"故事从歌里长出来" | 说得出故事从这首歌的哪里来吗？听过这首歌的人一看就懂吗？ | 歌名就是那件物 | 要解释半天才对得上 |
| F2 一人一事 | 画面本质①（全片围着一个具体的人） | 有一个具体的人做一件看得见的事吗？ | 一个小人物把一件事做完 | 群像、编年 |
| F3 金句对位 | 画面节奏本质③（揭示前停）/ 哲学"最狠的一句先亮" | 歌里最狠的一句能落在故事的揭示上吗？ | 金句和揭示是同一个画面 | 金句只能当背景 |
| F4 回扣物 | 画面本质③（同构图回扣） | 有一件东西（一句话）能在"那时"和"现在"各出现一次吗？ | 一件物两次出现、意思变了 | 没有 |
| F5 字好看 | 旁白本质③（屏上是好小说） | 写得出一篇单独拿出来读也好看的小说吗（有笑、有走、最后一句短）？ | 出处本身就有一句可当标题的话 | 只能写成史料摘要 |

五星要求每项 ≥4、均值 ≥4.5。作者默认（入画场景、4:3 或长图、冷调一块绿）不进契合题。

## 六力检验问题（本风格改写）

力的名字和星级线不改：
- 冲击：第一帧（结局）+ 歌的副歌，1 秒内能不能让人停下？
- 拥有：听过这首歌的人，看完会不会觉得"原来歌背后是这个"？（器物歌最强，地方 / 人物歌弱一档）
- 闭环：结尾是不是回到开头那一帧、金句落定？
- 留存：小说字能不能一段一段读下去？
- 分享：会不会转给"也喜欢这首歌"的人？评论区会不会补故事？
- 形式：能不能做成"一曲两章""图文版"等系列装置？

## 专有否决

| 项 | 判定 |
|---|---|
| 现代故事、现代职业 | 出局（红线 10） |
| 说不出来处 | 出局（红线 11） |
| 出处不是公版 / 用受保护 IP 人物情节 | 出局 |
| 写在世真人、需要可识别真人肖像 | 出局 |
| 同一事件本库他线已写 | 让位；同一人物可换一件没讲过的事 |
| 歌的发布路径走不通（无曲库、无授权） | 不出局，但只能做图文版或内部样片，标"发布待定" |
