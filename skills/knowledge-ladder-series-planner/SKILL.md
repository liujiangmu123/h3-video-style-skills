# 知识溯源科普 · 选题 skill（series-planner）

研发线用：由 `h3-research-director` 第 ④ 步调用。本技能只决定"做什么"（从哪个高中工具爬、爬到哪、做出什么、怎么排季），不写旁白、不写提示词（那是风格 skill `knowledge-ladder-explainer`）。判断一个题合不合适，用的是风格 skill 的哲学：**科普要对人有用——从见到，到困难，最后做出一个东西解决一个问题。**

## 方法

六阶流程、三个一票否决、爆火六力、星级判定树、每期字段、撞题、任务消息骨架、合规红线按 `h3-research-director/references/planning-method.md` 走；完整实例看 `shenhai-series-planner`。本技能只存这条线专有的判据、规则、数据和台账。风格 skill 缺的三层表、作者感觉、口径裁决补在 `references/fit-criteria.md`（方法文件第三节「基线缺件」）。

## 三元组（每期必须写得出）

**工具（一个高中就会用的工具）× 卡点（生活里会遇到的真问题，旧工具在它上面失败，失败能量成两个以上数字）× 成品（10 分钟内能复现、正好解决这个真问题的东西，带实测数字）**，外加：被命名的概念 + 一句溯源（人 + 年份）+ 唯一的主旋钮。写不全的不进库。

例：斜率 · 计算器只会加减乘除，它怎么算 sin（切线近似 sin 0.1 误差 0.0002，走到 1.5 误差 0.5）· 二十几行的 sin 计算器（先折回再取 6 项，0–360° 最大误差 5.6×10⁻⁸，样稿配套代码实测）→ 泰勒展开 · 1715；主旋钮 = 项数 N。

## 方向轴与来源

**学科轴**：一期 = 一条阶梯 = 一个高中工具长成一个高级概念、再做出一个东西。一期讲的是一个知识点，起点能从高中教材目录列出、终点能从大学一年级课程目录列出，所以按学科轴（池深线 ≥50，50–70 在线附近；方法文件第五节）。方向按"真问题出在哪"分：手机里 / AI 的来历 / 生活决策。

池深怎么枚举：高中工具（人教 A 版 2019 五册 + 物理必修里观众"会用"的约 25 件：斜率与导数、二次函数、指数对数、三角函数、向量、矩阵乘法雏形、数列、概率与树状图、统计、排列组合、圆与距离……）× 每件能长成的高级概念（2–5 个）× 方向里的真问题清单，再筛掉过不了四门的。枚举表在风格线 `风格量产\00_领域总览.md`；现有估值都是估算，开工种子包要逐方向枚举到线才算数。

候选来源（本风格特有）：
- 高中教材的"探究与发现 / 阅读与思考"栏目：它们本身就是从高中工具往外爬的阶梯（例：选必二"牛顿法——用导数方法求方程的近似解"，据深海 12 路线图第 254 行引电子课本目录，未再核）。
- 大学一年级课程目录（高数、线代、概率论、信号与系统、自动控制原理、数值分析、机器学习导论）：给终点概念。
- 手机系统自带 App 与相机功能清单（方向 2）；AI 史年表（莱布尼茨 1684 / 1703、布尔 1854、维纳 1948、香农 1948、罗森布拉特 1958，方向 1）；家庭账单、体检单、游戏规则说明（方向 3）。
- "学了 X 有什么用"一类提问与评论区（需求证据，待联网查证）；3Blue1Brown、Veritasium 选题（风格 skill `knowledge-ladder-explainer/references/reference-cases.md` 已核两条）。

## 规则（专有，优先于评分）

1. **起点必须是高中课本里有、观众会用的工具**。大学工具只能出现在第 4 级，作为推广的结果；起点要先讲一套新工具的题不进库。
2. **成品先写先跑**：片中数字全部来自运行输出（稿末附实测表）；代码 ≤40 行、只用标准库或一个常见库；做不出来、或要 GPU / 大数据 / 实验设备才看得到结果的题不进排期。选题库 `02_溯源阶梯选题库.md` 里写了"50 行"的（#18）要压到 40 行。
3. **真问题要真**：生活里会遇到，不用"考试会考"；冷开场是第 3 级困难的预告，结尾必须解决它。
4. **事实不夸大**：说"同一个思路"，不说"芯片就是用 X"（计算器 sin 实际多用 CORDIC 或 minimax 多项式，见风格 skill 参考案例）；溯源一处一句，人名、年份逐条核。
5. **合规切角**：医疗题（贝叶斯、CT）只讲概率与成像数学，不做诊断建议；金融题（复利、房贷）只讲机制，不比产品；定位题不出真实国界；密码题让 09 线；抽卡题只算期望与分布，不教充值策略；成品用到真实设备（Wi-Fi 定位、修照片）的，出片前实拍实测。
6. **一期一条阶梯、一个主旋钮**：不并列两条推广路线；超过 300 s 在第 3 级末拆上下集，不拆成连载。
7. **撞题让位**（下方「台账 · 撞题分工」）：一篇论文的讲解让 09；一个原理的变形讲解、考点题型让深海；本线只做"从高中工具爬上去 + 做出东西"这一侧。

## 查证

爆款实证与事实查证要联网：Pi 没有联网搜索，这一步在 Kiro / Cursor 里做，结论写回路线图"注记"。每期写稿前查四件事：
1. **溯源**：人名、年份、"第一次写成什么样"两源核对；有发明权争议的写"一说"（高斯 / 勒让德最小二乘、牛顿 / 莱布尼茨微积分）。
2. **说法不夸大**："X 就是用 Y 做的"一类句子查实际实现（计算器 sin 多用 CORDIC / minimax 多项式），查不到就改成"同一个思路"。
3. **成品能跑**：代码在本机跑一遍，输出与片中数字逐个对上；用到真实设备的出片前实测。
4. **撞题**：按上面的分工，在深海与 09 的选题表里检索本期关键词与冷开场句；撞了按「撞题表」三选一处理。
