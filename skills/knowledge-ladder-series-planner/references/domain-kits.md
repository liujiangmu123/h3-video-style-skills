## 方向2 你手机里的数学 · 风格线 `风格量产\03_方向路线图.md` 方向2

- 锚点：计算器（sin、√、log 三颗键，开场灰、结尾点亮）；相机取景框里的门框；斜拍的一张 A4 纸；调音器指针；收件箱里的"疑似诈骗"标签。
- 原子素材：白色真实对象线（曲线、门框、纸边）；青色切线 / 割线 / 近似线；右上角误差读数框；底部空白上方的滑块；计算器屏幕一行一行出数；红色误差面积。
- 代表阶梯：
  - #1 坡有多陡 → 斜率 → 切线走远就歪 → 加弯曲项 = 泰勒（1715）→ sin 计算器 + 拉直门框（样稿）。
  - #16 猜一个数再修正 → 切线方程 → √2 写不完 → 切线和 x 轴的交点一步步逼近 = 牛顿迭代 → 手写开方函数（从 1.5 起第 3 步误差 1.6×10⁻¹²，从 1 起第 4 步同样，本次 python 计算；片中数字以写稿时代码输出为准）。
  - #12 照片旋转缩放 → 坐标与一次变换 → 斜拍的纸四个角怎么都对不上 → 透视变换（8 个未知数）→ 点四个角把纸拉正。
- 成品类型：一个在手机或电脑上跑的小工具（计算器函数、修图脚本、短信拦截器、调音器）+ 一个 ≤3 步的手算版。
- 钩子类型：日常好奇（"它是怎么做到的"）为主；反常识（"它只会加减乘除"）；拥有感。
- 风险：撞深海 18 / 24 / 28 / 33 最多，立项前逐题查；"芯片就是用 X"的夸大；#12 要 numpy + 一个图像库，超出"一个常见库"（口径待定，见路线图）；用到真实设备的成品（#2 录音、#10 Wi-Fi）出片前实测；不点名在售 App 与机型。

## 方向1 AI 的家谱 · 风格线 `风格量产\03_方向路线图.md` 方向1

- 锚点：一排开关和小灯；热水器旋钮与水温读数；二十问卡片；投篮的球和篮筐；片尾的家谱台阶（跨期累加，一期点亮一级）。
- 原子素材：开关 / 灯点阵；0 和 1；真值表格子；反馈箭头环；误差读数；台阶。
- 代表阶梯：
  - #7 开关只有开和关 → 真值表 → 只有开关怎么算 3 + 5 → 二进制加法 = 与或非的组合（莱布尼茨 1703 二进制、布尔 1854、香农 1937，年份待核）→ 搭一个 4 位加法器（在线模拟器或 Python）。
  - #6 洗澡水忽冷忽热 → 一次函数与差值 → 按差值调会调过头、来回振荡 → 反馈 + PID（维纳 1948）→ 网页上调一个 PID，让小球停在杆上。
  - #5 二十问 → log₂ → 各种回答可能性不一样大时怎么量 → 熵（香农 1948）→ 算出猜词游戏的最好开局词（成品已改，见路线图撞题表）。
- 成品类型：模拟器（门电路、PID、感知机）与小游戏；跑出能上屏的数字（加法结果、振荡衰减次数、猜中步数）。
- 钩子类型：反常识（"一堆开关会算 3 + 5"）；日常好奇；热点搭桥（AI 正热，但不追突发新闻）。
- 风险：和 09 方向1、深海 28 撞题最多（感知机、反向传播、梯度下降、香农）：成品不能和 09 相同、直觉画面不用深海已出稿的；"今天的 AI 是这个梦的后代"只能说"思路上的祖先"，不说"AI 来自莱布尼茨"；年份多，逐条两源核；季末串联期等前面各期出片后再写。

## 方向3 算清楚再决定 · 风格线 `风格量产\03_方向路线图.md` 方向3

- 锚点：房贷合同上的月供一栏；自己的跑步记录；一包包随机卡片；一张飞行棋棋盘。
- 原子素材：时间轴；每期还款柱；散点与一条线；模拟次数计数器；直方图。
- 代表阶梯：
  - #9 利滚利 → 等比数列 → 一秒结一次息会不会变成无穷多 → e（伯努利 1683 提出、欧拉命名，待核）→ 自己写房贷计算器（按写稿当期利率现算，同屏标假设）。
  - #8 测几次取平均 → 平均数与方差 → 一堆点怎么画"最好"的线 → 误差平方和最小 = 最小二乘（高斯 1809，勒让德 1805 先发表，写"一说"）→ 用自己的跑步记录预测下一次成绩。
  - #13 古典概型 → 等概率集卡有公式 → 稀有款概率不一样，公式算不动 → 随机模拟 = 蒙特卡洛（乌拉姆、冯·诺依曼 1946）→ 40 行集卡模拟器。
- 成品类型：计算器与模拟器；结论是一个拿去就能用的数（月供、预测成绩、平均要买多少包）。
- 钩子类型：决策工具；拥有感；反常识。
- 风险：金融只讲机制，不荐产品、不给"该不该提前还贷"的建议；集卡、桌游只算期望，不教消费、不点名游戏与品牌；和深海 63 / 18 / 30 / 05 撞，钩子避开已出稿的；形式创意弱（六力形式 3），用母题"老办法 vs 新工具计时赛"补。
