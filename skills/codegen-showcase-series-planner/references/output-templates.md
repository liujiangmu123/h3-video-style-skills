# 任务消息（本风格专有部分）

通用骨架见 `h3-research-director` 的 planning-method 第八节。这里补：

- **必读文件**：`codegen-style-showcase` 全文与 `references/style-dna.md`（主配方、选题门、段卡模板、出片、红线、自检必读）；本期用到的每一张风格卡 `风格量产\风格卡\NN_*.md`（风格块、10 秒节拍、试片词、坑）；`风格量产\01_风格块与引擎分工.md`；B 线整段提示词按 `h3-prompt-writing`（三字段）与 `h3-director`「多镜头线出片」；每段的生长和最大变化按 `creative-animation-treatment`；写画面前查 `h3-production-lessons`。
- **锁定参数**：B 线多镜头（模式 A），每个芯一条 T2VA，243 帧（10.125 s，17k+5 网格）；事件约在 0.3 / 2.0 / 4.0 / 6.3 / 8.0 s，最大变化在 6.3 s 前后（约 63%），8.0 s 后静住；无旁白；`non_diegetic_music` 每段写一首像这个风格的曲子（拍速参考风格卡）；16:9。外框、说明卡、编号、进度条、落版字标、片头片尾、段间过桥那颗点全部走代码层——引擎未装时用 ffmpeg 叠编号和落版字，片头片尾可以先做成静帧。
- **说明卡**：每段 3 行、每行 ≤19 字（零件 / 判断 / 动作链）、两个技术标签；0 问号 0 叹号 0 第一人称；作品名 = 技法。
- **每期条目必带**：三元组（题 / 芯清单 / 引擎分工）；芯清单每行写 编号 · 风格卡 · 最小单位 · 最大变化 · 落版；每张说明卡三行草案；比较轴；撞题与 IP / 商标检查结果；创新档。
- **特殊红线**：不复刻 V01 的作品、作品名、字标、说明卡原文；标题不用"Opus""Claude"；不画 IP 角色、在世名人、品牌标志性产品；HUD 不锁真实地点；H3 提示词里不写任何要读的字（字全在代码层）；片里不问"你喜欢哪个"、不喊关注。
