# 领域套件（每个方向一节；不写 hex）

公共：外框按风格 skill（暗底、说明栏 + 作品屏两栏、每段左右交替、编号 / 短横 / 进度条当前格 = 该段主色，都是作者默认，可带理由换）；一屏 2–3 种颜色；每段 10 s 左右，最大变化在 58–72%；段间静音 + 一颗点过桥，不硬切。芯的风格块、10 秒节拍和试片词在 `风格量产\风格卡\NN_*.md`，按卡写，不在这里重写。

## 方向01 一物 N 画 · 风格线 `风格量产\方向01_一物N画\`

- 题怎么选：一个人人见过的日常东西（水果、杯子、伞、猫、自行车、纸飞机……）；形状简单、一眼认得、能缩成一个最小单位（橘子 = 一颗橙色圆点）；没有 IP、没有商标。
- N：6–9。引擎未装时芯只从 H3 为主（05 3D、06 形变、09 拼贴、12 Synthwave、14 液态）和混合（01 手绘、03 扁平、08 HUD、15 花字）里挑，9 个正好全用上。
- 每个芯要写出：最小单位（这件东西在这个风格里怎么缩成一点）→ 生长 → 约 63% 的最大变化 → 落版（这件东西的一张海报 / 封面 / 贴纸，字标由代码叠）。
- 排序（推断，未实测）：相邻两段的颜色和软硬拉开（扁平之后接 3D，液态之后接拼贴）；花字是竖屏、最吵，放最后一号，正好接总览格。
- 比较轴：编号。总览格把 N 个一次摆齐，评论区自然出现"我选几号"；片里不问。
- 风险：九段都变成"同一张图换滤镜"——每个芯的最大变化要用这个风格自己的动作（液态是融合、拼贴是剪开、形变是一形变另一形）；HUD 那段别锁真实地点。

## 方向02 一颗点的一生 · 风格线 `风格量产\方向02_一颗点的一生\`

- 题怎么选：一个"一生"——一个人、一座城、一件东西、一段感情，分 5–7 幕；每一幕的风格由年代或心情决定（出生用液态"一滴"，童年用手绘，热闹用花字，回忆用拼贴，晚年用线条或形变收成一点）。
- 主角就是 V01 用来过桥的那颗点：它从第一幕滑进下一幕，每进一幕就长成那一幕的风格。
- 外框不变（这一点守住 F1）；只有最后一幕落成成品（F3 只有 3，是这个方向的短板），中间幕停在"一个状态"上。
- 风险：变成"风格接力 MV"，故事被风格冲散。每幕只做一件事，用一个最小单位起、一个最大变化落。

## 方向03 用风格讲风格 · 风格线 `风格量产\方向03_用风格讲风格\`

- 题怎么选：一期一种绘画 / 平面 / 媒介风格（包豪斯、像素、拼贴、浮世绘、波普、蒸汽波……），用这个风格自己的样子讲它是怎么来的；界面、颜色两类让深海。
- 要一个故事钩子：风格史单讲量中等（包豪斯 40.7 万、像素简史 1.2 万，取证 §5），带钩子的才起量（"被纳粹封杀的破学校"）。
- N 在这里是"这个风格的 N 个时刻"（诞生、成名、被抄、变成日常），同一个框装同一种风格的 N 个时期。
- 客串：每 3–4 期方向01 插 1 期；风格反串（用花字讲包豪斯）进 B 档母题。
- 风险：讲成风格史纪录片，丢了"比"；史实要查证（日期、人名、学校名），简介写出处。
