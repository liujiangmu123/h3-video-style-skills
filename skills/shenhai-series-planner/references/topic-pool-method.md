# 从方向到期：选题池构建法

> 方向评了五星只是许可证。一个方向能不能活到 300 期，取决于这里的枚举法、配对法和体检法。本文件把 70 个领域已经跑通的做法（种子包 50 期 → 路线图 051–300）写成可复用步骤。

## 一、结构：六单元起步，六季到 300

**种子包 50 期 = 六单元**（默认顺序，可按学科模块改）：

| 单元 | 期号 | 任务 | 难度 | 爆款指数要求 |
|---|---|---|---|---|
| 一 · 入门钩子 | 1–9 | 全民日常问题，零门槛（天为什么蓝 / 前面没事故你在堵什么） | 1 | 第 1 期必须 5，单元内 ≥4 为主 |
| 二 · 核心原理 | 10–18 | 该方向的"几个动作"（光的四个动作：反射 / 折射 / 散射 / 干涉） | 1–2 | ≥3；这是公共锚点的"发布会" |
| 三 · 历史案例 | 19–26 | 有人物冲突的科学史 / 设计史（一个医生挑战牛顿） | 2 | ≥3，至少两期 5 |
| 四 · 现代应用 | 27–34 | 屏幕里 / 手机里 / 家里的实例——商单空间所在 | 2 | ≥4 |
| 五 · 进阶冷知识 | 35–42 | "你的眼睛在撒谎"类反常识 | 2–3 | ≥3，至少两期 5 |
| 六 · 跨界联动 | 43–50 | 与相邻领域互链（光 × 设计 / 艺术史 / 生物 / 天文），片尾互导 | 2–3 | ≥3 |

**300 期 = 六季 × 50**，每季一个主题弧（入门钩子季 → 核心原理季 → 历史长廊季 → 现代应用季 → 冷知识季 → 跨界季，或按学科模块）。每季难度有梯度，每季第 1 期是该季最强钩子。

## 二、四门配对法（每期的出生证）

一期不是"讲一个知识点"，是一个三元组：

```
原理（过第 2 门：20 秒无字可演） × 证物（过第 3 门：真东西，能叠骨架线） × 手边物（过第 4 门：观众自己有）
```

枚举步骤：

1. 列出该方向**所有可演示的原理**（只能陈述的不算——"熵增"不算，"热从热往冷跑、画出等温线"算）。这一步得到的数量就是池深的硬底。
2. 给每个原理配 ≥1 件证物：名画 / 名建筑 / 名照片 / 经典产品 / 实验装置 / 史料图纸——必须是可以矢量重绘并在上面画出原理骨架线的东西。
3. 给每个原理配 ≥1 件手边物：手机功能、家里器物、身上部位、日常票据。配不上的期标注"无手边收尾"，整个方向此类期不超过三分之一。
4. 同一原理换证物或换手边物可以再成一期，**但角度必须不同**（一期讲"为什么"，另一期讲"怎么被利用 / 怎么翻车"）；只是换例子不算新期。
5. 把三元组写进选题条目的"核心知识点 / 建议锚点 / 查证要点"三列——生产层据此直接出分镜，不用再猜。

## 三、每期字段与口径

选题库固定八字段：`期号 | 标题 | 一句话钩子 | 核心知识点 | 主锚点 | 难度(1-3) | 爆款指数(1-5) | 查证要点`；种子包再加"钩子类型"与"创新档"两列。

**爆款指数**：5 = 全民钩子（不懂领域也会点）；4 = 强（有明确人群会转发）；3 = 稳（垂类内常青）；2 = 垂类（只有学过的人在意）；1 = 养号（补完整性）。一个 50 期种子包里 5 分不少于 8 期，2 分以下不多于 5 期。

**难度**：1 = 一句话说得清的现象；2 = 需要一条变形链演示的机制；3 = 需要两步推理或前置概念的机制。难度 3 不进第一单元。

**钩子类型**（每期标一种主类型）：考试刚需 / 日常好奇 / 拥有感 / 反常识 / 热点搭桥 / 决策工具（定义见 `rating-rubric.md` 第五节）。

**标题规则**：≤18 字；深海式短句——双关（反正你一定会看 = 双向图）、梗（我又相信光了）、否定或反差（它从未发生过）、拟人（钢会累桥会记仇）、数字反差（二十美元拍出两百块）；不出现术语原文，不用"今天讲……"，不用"第 X 章"。一句话钩子写观众视角的具体画面或反差，不写摘要。开场句式的具体模式库见 `shenhai-style-explainer/references/hit-mechanics.md` 第三节，同型开场任意连续 5 期 ≤2 次。

## 四、创新档（每期标注，供生成层决定是否调用创意 skill）

深海的规则分三层（`style-dna.md` B-0 三层表）：第 1 层本质永不变（一次只变一件、事件间死停、一枚迟到的强调色、零剪辑、演示先于命名、旁白规格），第 2 层作者默认是带理由可以偏离的底子，第 3 层每期自由（画布、强调色、母题、动词、唯一破规、开场句）。本 skill 用三档告诉生成层这期在第 2、3 层里走多远。**画面档位（B6）不是创新档**：A / B / C 每期都按领域的主档与范围定，A 档也要把住户画出来：

| 档 | 名称 | 含义 | 何时用 |
|---|---|---|---|
| A | 常规 | 按配方直走，母题取该方向的公共锚点，不额外发明 | 单元二 / 单元四的大多数期；难度 1 的日常好奇期 |
| B | 母题创新 | 指定一个贯穿全片的图形装置（skeleton over logos / 屏幕翻转 / 波长游标），案例全部作为它的证据 | 爆款指数 4–5 的期；历史案例与冷知识单元 |
| C | 形式即内容 | 整片视觉语言由题材自身材料构成（讲线的片用线画海、讲光的片用光点搭铁塔）；生成层须调用 `creative-animation-treatment` 整片模式，并把三层表第 1 层与 B6 档位范围作为不可打破规则交给它 | 每季第 1 期；方向的"定妆照"期（如光学的 1666 暗室）；用户点名的旗舰期 |

分配比例参考：A 六成、B 三成、C 一成。C 档一季不超过 5 期——原片 13 支里形式即内容的也只有约三分之一，其余靠纪律。

## 五、体检与撞题（存量复核与建库都要做）

**体检三分**：每期打 钩子潜力 / 获得感 / 大众度 各 1–5，**任一项 ≤2 判弱种子**。弱种子三选一：改造（换日常入口前置——"增透膜人人见过"代替"波峰遇波峰"）/ 替换（换镜像题——"多一种"的四色视觉代替与邻频道相撞的色盲）/ 删除。

**撞题三选一**（与邻近频道种子包全文比对后）：

| 处理 | 适用 | 写法 |
|---|---|---|
| 分工保留 | 同一现象两侧可分（硬件侧 vs 人眼侧） | 逐字注明本期只讲哪一侧，片尾互导对方频道 |
| 替换 | 核心机制与查证要点都重合 | 换镜像题或相邻题，原位顶替 |
| 收窄 | 部分重叠 | 重心改到不重叠段，重叠段"带一句"让出 |

不允许"两边都讲一遍"；处理结果写进路线图的"重叠预警 / 处理"两列。

## 六、051–300：分簇、分季、可持续性

1. **分簇**：新增 100 题按 6 簇两季（例：第三季"抬头与身边"= 自然光魔术 18 + 色彩科学 16 + 看不见的光 16；第四季"深入本体"= 波动光学 16 + 激光现代光学 16 + 仪器解剖与量子初探 18）。簇内难度以 1–2 为主，季末簇允许 3，用强故事期对冲大众度衰减。
2. **常青优先**：全部选题默认常青；时效题（新品发布、年度天象）单列"自补给线"，不占常青编号。
3. **可持续性评估**（路线图必写）：剩余版图概算（还有多少个过四门的原理没用）+ 自补给线（每年能新增多少期的机制：天象年历 / 显示照明新品 / 前沿与翻车）+ 真正的约束（通常不是没题，而是跨频道边界磨损与风格纪律长跑）+ 对策。结论只能是"不枯竭（有条件）/ 到第 N 期见底"两种，条件写清。
4. **边界备忘**：路线图第二节固定写"三面受敌"表——哪几个邻近频道各切走哪一块，逐期对表。
5. **生产回流**：每个领域文件夹里的 `_故事素材库.md` 是生产代理查证时挖到、当期未用的轶事 / 反转 / 数字反差，每条已标"建议用途"（选题种子 / 备选簇 / 彩蛋 / 需与哪个频道划界）。展开 151–300 或补替换种子时先扫这份文件，再去外部搜——它是零成本、已带出处、已过合规初筛的自补给。

## 七、排期原则

- 第 1 期永远是本方向最强钩子（爆款指数 5、难度 1、创新档 C）。
- 每季第 1 期 = 该季最强钩子；每季末一期做跨界互导。
- 连续 5 期同型开场 ≤2；"影史最 X / 史上最 X"类每 10 期 ≤1。
- 商单意向领域的现代应用单元前移到第二季，给品牌留接口，但机制半场永远不缩短（`style-dna.md` A9.7）。
- 与生产节奏对齐：每批 50 期一个批次文件夹；路线图给到 300，选题库先建 150，剩余 150 在第 100 期投产时再展开（避免过早锁死）。
