> 两次成功的方向发现都是"来源扫描 → 并行子代理 → 主对话合并终审"：2026-08-12 用 11 个子代理扫出学科轴 42 个新五星（`领域拓展调研_2026-08-12\`），2026-08-26 用叙事单元推演扫出 25 个方向（`爆款方向探索_论文科普与多方向量产\`）。本手册把两次的来源与规矩固化，下次不必重新发明。

## 三、子代理分工（允许并行时）

- **方向发现阶段**：按来源分组，每组 1 个子代理，同时跑；每个子代理产出一份《NN_来源名.md》，格式统一：调研范围 → 候选清单（名称 / 一句话定位 / 原子 / 锚点 / 池深估计 / 钩子类型 / 初评星级 / 合规提示）→ 明确否决项及理由。主对话只做合并、去重、终审定星，不自己再搜。
- **种子包阶段**（每方向）：4 个子代理分别搜——教材 / 考纲 / 经典书目录；B 站 / 抖音 / 小红书爆款与知乎高赞；国外同类频道选题；权威事实源（用于雷区表）。主对话汇总成种子包。
- **子代理提示词必须自包含**：把评级口径（`rating-rubric.md` 第一、二、四节）和字段定义（`output-templates.md`）复制进任务描述，不能只给路径。

## 四、实证与留档规矩

1. **播放量级必须带来源**：平台 + 账号 + 数量级（"Veritasium 5060 万" / "B 站单集 122 万"）。查不到量级的写"讲法参考"，不得作流量背书。
2. **数字宁可不给，不可给错**：种子包的查证要点里所有数值标"约"或给精确定义来源；生产期上屏前仍须回原文复核。
3. **来源覆盖硬要求**（选题库）：教材 / 考纲目录、B 站 / 抖音 / 小红书爆款、知乎高赞、国外同类频道、经典书目录五类全覆盖；至少三分之一选题来自联网实证的真实流量话题。
4. **留档位置**：方向调研报告放调研文件夹（如 `领域拓展调研_YYYY-MM-DD\`），种子包与选题库放该方向文件夹；报告开头写调研日期、任务、标准版本。
5. **重叠登记**：新方向与现有 70 领域 / 25 方向的重叠度写在评级表最后一列；>30% 的在建库阶段逐期比对。

## 五、撞题扫描范围（种子包与路线图阶段必做）

以光学与色彩为例的邻近频道：数码科技原理（屏幕硬件）、眼视光（眼睛）、摄影（相机）、艺术史（名画光色）、高中物理（光电效应）、傅里叶（波）、化学（焰色）、生物（叶绿素）、天气（彩虹 / 极光）、天文（光谱）、互联网（光纤）。方法：把本方向每一期的核心知识点，在邻近频道的 `_开工种子包.md` 与 `_选题库_*.md` 里全文检索；命中即进撞题表，三选一处理（见 `topic-pool-method.md` 第五节）。

## 六、迁移盲测（评级后、建库前）

任选 1 个新五星方向，按配方写一段 30 秒的**纯文字**节拍骨架（不写提示词）：原子 → 第一次变化 → 证物叠骨架 → 手边物。自检两问：关掉声音认得出领域吗？看构图认得出作者吗？两问有一问答不上，回到锚点套件重做。
