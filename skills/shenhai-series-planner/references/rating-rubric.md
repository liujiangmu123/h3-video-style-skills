# 方向评级标准 v3（2026-09-05 合并版）

> 版本脉络：v1 五项风格契合（2026-08 初）→ v2 追加"池深 ≥50 期 + 大众吸引力"两项硬指标（2026-08-12，三个方向因此从五星降四星）→ 叙事单元线引入七维评级与爆火六力、把"收藏价值"升为准一票否决（2026-08-26）→ 2026-09-05 帧级重读补入四门。v3 把这四套口径合成一张表，两条方向轴通用。
> 使用顺序不能颠倒：**先一票否决，再风格契合与四门，再爆火六力，最后定星。** 顺序颠倒会把"风格很像但没人看"的方向评成五星。

## 一、三个一票否决（任一不过，直接出局或降为客串单元）

| # | 否决项 | 检验问题 | 不过的处理 |
|---|---|---|---|
| 1 | **H3 可生产性** | 这个方向的视觉字母表能否全部矢量化？有没有"演变 / 生长 / 对比"类知识能做连续 morph？必须依赖实拍质感、真人面孔、复杂写实纹理吗？ | 依赖实拍即否决（美食测评、旅行风光、情感访谈、动作技能教学都在此倒下） |
| 2 | **合规安全** | 是否涉及医疗诊断 / 用药指导、荐股 / 保险比价、政治民族、未定案人物指控、地图国界、赌博技巧？能否改切角规避？ | 能改切角就改（只讲机制不碰标的；用拓扑节点图替代地图），改不了就否决 |
| 3 | **池深** | 能否稳定产出不重复的选题——学科轴 ≥50 期、叙事单元轴 ≥100 期？用"原理枚举法"证明：先列出该方向所有**可演示**的原理，再数能配的证物。 | 不到线的降为客串单元（挂在相邻方向下穿插），不单独立方向、不建文件夹 |

池深为什么分两档：学科有考纲和教材目录托底（一科 100+ 知识点），叙事单元靠人工枚举物件，B 站常识科普赛道"入场易、持续难、头部从百万跌到 20 万级"的教训说明 100 期是穿过同质化坎的最低储备。

## 二、风格契合五项（每项 1–5 分）

| 项 | 5 分长什么样 | 1–2 分长什么样 |
|---|---|---|
| **视觉字母表** | 领域自带可扁平矢量化的原子（音符、笔画、硬币、箭头、等高线） | 原子要靠比喻硬造（"一个念头"→气泡） |
| **变形潜力** | 概念之间能连续 morph：演变链（甲骨文→楷书）、生长（细胞分裂）、对比（正/斜） | 知识是离散事实堆，只能一张张切换 |
| **案例阶梯** | 有"历史名作 → 经典应用 → 现代产品 / App"的证据链 | 只有理论没有实物，或实物必须实拍 |
| **锚点辨识度** | 有一眼认出领域的容器 / 记号（五线谱、田字格、取景框、K 线、受力图） | 关掉声音认不出是哪个领域 |
| **概念密度** | 有足够专业术语做中英概念卡（每期 1–2 张不重复） | 术语过少，或全是不可翻译的口语概念 |

五项平均 ≥4.5 才有资格进五星候选；**只看这五项就定星是 v1 的错误，已被 v2 否定**。

## 三、四门（方向级用法）

四门本体在 `shenhai-style-explainer/references/style-dna.md` B-0（原子 / 20 秒可演 / 骨架可叠证物 / 观众手边）。方向级检验方法：从该方向抽 5 个代表性原理，逐个过四门。

- 5 个全过第 1、2 门 → 方向成立。
- 有原理只能陈述不能演示（第 2 门）→ 这类原理占比超过一半，方向降一星；这些原理本身不进选题库。
- 第 3 门不过（没有可叠骨架的真东西）→ 该原理只能做"纯几何演示期"，方向内此类期不超过三分之一。
- 第 4 门不过（观众手边没有实例）→ 允许，但失去 A9.3 手边收尾；整个方向都过不了第 4 门的（例：纯天文尺度）要靠"手机里的 App / 身上的东西"补桥。

## 四、爆火六力（每力 1–5 分）

| 力 | 定义 | 检验问题 |
|---|---|---|
| **认知冲击力** | 观众原有认知被打断的强度 | 看完第一句会不会"啊？" |
| **拥有感** | 主题是不是观众身上 / 手里 / 每天在用的东西 | 观众会不会想"这东西我有" |
| **闭环快感** | 问题 → 线索 → 机制 → 答案在片内闭合 | 看完有没有"讲完了"的舒适感 |
| **留存价值** | 未来某个时刻还有用（2026 第一权重：收藏） | 观众会不会点收藏"以后用" |
| **分享动机** | 存在明确的"转给谁" | 会不会想"转给我爸 / 我同事 / 我孩子" |
| **形式创意** | 表达形式与内容同构、静音认得出栏目 | 关掉声音看画面还认得出这是哪个方向吗 |

**五星线：六力至少四项满分、无一项低于 3。** 收藏（留存价值）低于 3 的方向即使其余满分也不进五星——这是 2026 年平台权重决定的，不是审美偏好。

平台机制取证（2026）：抖音权重 收藏率 > 转发/复访率 > 完播率 > 评论率 > 点赞率；发布后 7 天内持续获得收藏与复访仍可触发二次推流，知识型长尾优于热点型；完播基线 3 秒留存 ≥55%、整体完播 ≥30–38% 进高阶池；B 站知识区重回百大第一分区，播放分钟数入权重，150–270 秒长版是正资产。

## 八、全局合规红线（评级与选题都要过）

1. 金融：荐股按实质认定，免责声明无效；保险禁试算比价——只讲机制，永不出现在市标的。
2. 医疗：不做诊断 / 治疗 / 用药指导；急救只讲原理并标注"不替代线下培训"；防蓝光、护眼灯、频闪伤眼类不下医疗结论。
3. 地图：不出现精确国界动画；用拓扑节点图 / 无国界色块替代。
4. 体育：战术与规则层可画，动作示范层一期都不能碰。
5. 心理学 / 哲学：每拍必须绑定具体实验 / 思想实验场景，禁止裸讲概念。
6. 人物：在世企业家不做人身化叙事；未定案指控不做；传说桥段标注"待核"。
7. 品牌：机制讲透，不点名在售品牌型号做导购对比——商单空间反而留住。
8. 版权：真实作品 / logo 一律矢量重绘表达；现行商标不 1:1 复刻；宗教 / 政治符号不做。
