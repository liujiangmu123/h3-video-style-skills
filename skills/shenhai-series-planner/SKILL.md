# 深海方向与选题规划 Shenhai Series Planner

## 定位与边界

这个 skill 只回答两个问题：**深海风格还能做哪些方向、哪个最好**；**选定的方向一期一期怎么排**。它不写旁白、不写 H3 提示词——产出物交给生成 skill `shenhai-style-explainer`。

它属于研发线（总入口 `h3-research-director`）。研发线的通用选题方法在 `h3-research-director/references/planning-method.md`；**本 skill 是那套方法在深海线的完整实例**，深海线的判据、数据和口径以本 skill 为准。给新风格做 planner 时拿本 skill 当样例，别直接套深海的四门和领域套件。

```
研发线：本 skill                                          生产线：h3-director
   找方向 → 评级 → 种子包 → 选题池 → 路线图 → 任务消息  ──▶  shenhai-style-explainer 写稿
                                                              → h3-storyboard-writing 分镜 → 工具出片
                                                         （创新档 C 时叠 creative-animation-treatment）
```

引用方向只向下：本 skill 读 `shenhai-style-explainer/references/style-dna.md`（B-0 哲学与四门、三层表；B6 画面档位）和 `shenhai-style-explainer/references/hit-mechanics.md`（爆火机制），**引用不复制**。风格规则、语速、节奏数值全部以那两份为准；本 skill 只决定"做什么"，不决定"怎么像深海"。

## 六条核心判断（评任何方向之前先默念）

1. **深海风格 = 固定动画语法 × 领域视觉字母表。** 找方向就是找字母表，再过四门（原子 / 可演 / 骨架可叠 / 手边）。字母表在，语法一条不改。
2. **判断口诀：** 知识若能"画在黑板上讲清楚"，适合；若必须"拍给你看才信"，不适合。
3. **风格契合再高，没有池深和大众钩子就是四星。** 四星只能做穿插单期，不能立主栏目——动画原理、围棋、诗词格律都是这样降下来的。
4. **2026 平台机制：收藏率是第一权重**（收藏 > 转发/复访 > 完播 > 评论 > 点赞）。选题必须自带"以后还要用 / 还要查"的属性；纯猎奇天花板明显。
5. **一期 = 一个原理 × 一件证物 × 一件手边物。** 不是"讲一个知识点"，是把过了四门的原理，配上一件能叠骨架的真东西和一件观众自己拥有的东西。这个三元组写不出来的选题不进库。
6. **极简是注意力设计，不是世界的大小。** 深海原片只画点线面，是因为他讲的就是平面设计；别的领域的知识住在哪里，画面就要画到哪里（`style-dna.md` B6：R1 符号 / R2 图解 / R3 剪影舞台 / R4 纸艺）。换圆点测：把画面里的具体东西换成圆点，知识还在 → R1；不在 → 住户必须画出来。每个方向定主档和范围，写进种子包和任务消息（初分见 `references/domain-kits.md`「Register Map」）。

## 两条方向轴

| 轴 | 切法 | 契合看什么 | 现有资产 | 池深五星线 |
|---|---|---|---|---|
| 学科轴 | 按学科 / 专业课 / 考纲切（物理、免疫学、高中地理……） | 视觉字母表 + 四门 | 70 领域已立项（编号 01–70，`references/domain-ledger.md`） | ≥50 期（考纲类天然 100+） |
| 叙事单元轴 | 一期拆一个 X（一张专利图纸、一个符号、一种颜色……） | 单元清晰度 + 拥有感 + 可查证 | 25 方向已评级（`爆款方向探索_论文科普与多方向量产\01_方向总览与评级.md`） | ≥100 期（B 站常识科普赛道"入场易、持续难"的教训） |

两轴同一知识点可各讲一次，**角度必须不同**；重叠度 >30% 的新方向建库时逐期与对应老领域选题库比对（见 `references/topic-pool-method.md` 第五节撞题处理）。用户提出的新方向先判断属于哪一轴，再选对应的评级口径。

## Workflow（六阶，缺输入先问）

开工前问清（用户没说就问）：账号阶段（新号 / 已有栏目）、平台侧重（B 站 / 抖音 / 快手 / 视频号）、是否有点名方向、目标期数（20 / 50 / 300）、是否有商单意向领域、是否允许联网与派子代理。

**阶段 0 · 读基线。** 读 `style-dna.md` B-0（四门 + 三层表）、B6（画面档位）与 `hit-mechanics.md`；读 `references/domain-kits.md` 的「Register Map」知道各领域的主档；读 `references/domain-ledger.md` 知道哪些方向已立项、产到第几期，避免重复立项。

**阶段 1 · 找候选。** 按 `references/research-playbook.md` 的来源清单扫（高中课本目录、大学专业目录、国外科普频道选题、中文生态空白、生活方式、社科人文、商业金融、体育新兴；叙事单元轴另有一组来源）。要求候选 ≥25 个、跨度有意外（不许全是安全近邻），每个一句话理由。允许派子代理时按来源分工并行，主对话汇总。

**阶段 2 · 评级。** 逐个过 `references/rating-rubric.md`：先三个一票否决（H3 可生产性 / 合规 / 池深），再风格契合五项 + 四门，再爆火六力，最后定星。产出《方向评级总表》+ 否决与受限清单 + 与现有领域的重叠说明。**只看风格契合不看池深与钩子的评级无效。**

**阶段 3 · 定方向与立项顺序。** 选五星；排序依据：零门槛 + 拥有感 + 制作重量轻的先做（适合早期建立栏目认知），考据链长、制作重的放后段，形式创意最强但需要成熟经验的放风格稳定之后。每个方向写一句话定位与最关键的查重 / 合规要点。

**阶段 4 · 开工种子包（每方向一份）。** 按 `references/output-templates.md` 第二节：爆款参考 ≥15 条联网实证（平台 / 账号 / 播放量级 / 可借鉴点）→ 流量结论（三类打法）→ 50 期种子（六单元，每期字段齐全）→ 锚点套件草案（八槽位 + 画面档位 + 住户圣经草案，按 `references/domain-kits.md` 格式；画布与强调色只写推导结果的词语和理由，**不写 hex**）→ 合规与事实雷区（数值必查表 / 史实易错点 / 表述红线 / H3 工程注意）。

**阶段 5 · 选题池到 300 与路线图。** 按 `references/topic-pool-method.md`：存量体检（钩子 / 获得感 / 大众度各 1–5，任一项 ≤2 判弱）→ 撞题扫描（邻近频道全部种子包）→ 051–300 分簇分季 → 可持续性评估 + 自补给线。产出《选题路线图_051-300》（含 051–150 全表）；第 100 期投产时再展开《选题库_151-300总表》，展开前先扫该领域 `_故事素材库.md` 里的生产回流余料。

**阶段 6 · 交接。** 为每个方向写一条《任务消息》（模板见 `references/output-templates.md` 第五节），必读文件列生成 skill、`h3-storyboard-writing`（产线分镜）与 H3 skill；每期条目带四门三元组、爆款指数、钩子类型、**创新档**（A 常规 / B 母题创新 / C 形式即内容，定义见 `topic-pool-method.md` 第四节）与查证要求。交接后本 skill 的工作结束。

## 硬规则（违反任何一条，产出作废重做）

- **三个一票否决先过**：字母表不可矢量化或无连续变形潜力 → 否决；触碰合规红线（医疗诊断建议、投资建议、政治民族、未定案人物指控、地图国界）且无法改切角 → 否决；池深不到线 → 降为客串单元，不立方向。
- **每期必须写出四门三元组**（原理 / 证物 / 手边物）。写不出证物的期不进库；写不出手边物的期可进库但标注"无 A9.3 收尾"。
- **零重复**：同一知识点换角度才算不同期；同一方向内零重复，与邻近方向撞题必须按"分工保留 / 替换 / 收窄"三选一处理并注明。
- **实证要求**：爆款参考必须带平台、账号、播放量级；选题库中至少三分之一来自联网实证的真实流量话题（爆款视频、知乎高赞、考纲高频）。播放量级未核实的只能写"讲法参考"，不能作流量背书。
- **标题深海式**：≤18 字，悬念 / 反差 / 拟人 / 双关，不出现术语原文，不用"今天讲……"；第 1 期永远是本方向最强钩子。
- **画布与强调色不写 hex**，只写推导理由与色名（"近黑暗室感 / 光谱金"）；具体色值由生成 skill 按 `style-dna.md` B1/B2 现场推导。
- **每个方向写画面档位与住户**：主档 + 范围（R1–R4，`style-dna.md` B6）+ 一句理由（知识住在哪里 / 换圆点测），以及画面里必须出现的具体东西。只给容器（画框、时间线、坐标、场记板）不给住户的锚点套件作废——2026-10-01 电影视听语言实测：容器 + 圆点，观众认得出领域，看不见知识。本 skill 不写英文风格块，那是生成层的事。
- **不复制风格规则**：任务消息里引用 `style-dna.md` 各节编号（A6 节奏、A7/A8 旁白、A9 结构），不抄数值——数值改一次只应改在一处。
- **不替生成层做决定**：不写分镜、不写节拍表、不写 H3 提示词；最多给一条 30 秒的纯文字节拍骨架做迁移盲测。

## 质检清单（交付前逐项打钩）

- [ ] 候选 ≥25 个且跨度有意外；每个候选有一句话理由与所属轴
- [ ] 评级表每行含：三否决结论 / 契合五项 / 四门 / 六力 / 池深估计 / 星级 / 与现有领域重叠说明
- [ ] 五星方向六力至少四项满分、无一项低于 3；池深达线有枚举依据（能列出 ≥50 或 ≥100 个不同原理，不是拍脑袋）
- [ ] 种子包：爆款参考 ≥15 条带播放量级；50 期六单元；每期八字段齐全；锚点套件八槽位齐全且无 hex；画面档位（主档 · 范围 · 理由）与住户圣经草案已写，和 `domain-kits.md` 档位表的初分一致或写了改的理由；雷区四小节齐全
- [ ] 每期四门三元组可核对；标题 ≤18 字深海式；第 1 期是最强钩子
- [ ] 体检表：钩子 / 获得感 / 大众度三分齐全，弱种子给出改造或替换方案
- [ ] 撞题扫描覆盖所有邻近频道种子包，处理方式三选一注明
- [ ] 300 期可持续性给出剩余版图概算 + 自补给线
- [ ] 任务消息必读文件路径全部存在（含 `hit-mechanics.md` 与 `h3-storyboard-writing`，不含已迁出的文件）；创新档逐期标注
- [ ] 全文无 3.0–3.5 字/秒、字数÷3.2 之类的旧语速数字；节奏与旁白规格一律"见 style-dna A6/A7/A8"；唯一允许的字数口径是产线预算"目标秒数 × 3.5"（总指导 §4.2）

## Failure Handling（症状 → 修正）

- 候选全是安全近邻（又是数学、又是物理）→ 强制补叙事单元轴候选与生活 / 商业 / 体育来源；跨度不够不进阶段 2。
- 评级全是五星 → 池深没有枚举、六力没有打分。回到 rubric 逐项写分，池深必须列出前 20 个不同原理作抽样证明。
- 池深虚高（说 300 期，实际 30 期见底）→ 用"原理枚举法"：先列该方向所有可演示的原理，再乘可配的证物数；只算过四门的组合。
- 选题大众度低（垂类自嗨）→ 每期先找手边物入口（观众身上 / 手机里 / 家里），入口找不到的降爆款指数或删。
- 标题像教材目录（"第三章 折射"）→ 用 `hit-mechanics.md` 的钩子模式库改写：实物直入 / 认知翻转 / 悬念反转 / 数字反差 / 直指痛点 / 新鲜类比 / 反高潮自答 / 感官验证。
- 与老领域撞题 → 三选一：分工保留（各讲一侧，片尾互导）/ 替换（换镜像题）/ 收窄（让出重叠段）；不允许"两边都讲一遍"。
- 种子包写了 hex 或抄了节奏数值 → 删，改为推导理由词语与 style-dna 节号引用。
- 任务消息把 4 个文件写成必读但目录里不存在 → 对照 `shenhai-style-explainer/SKILL.md` Reference Files 段重列。
- 生成层反馈"这期演不出来" → 四门第 2 门没过：原理只能陈述不能演示；换原理或换方向，不要靠旁白硬讲。
- 成片"元素极简、像信息图、看不懂知识" → 锚点套件只有容器、没有住户，或档位定低了：按换圆点测重定主档，补住户（人、器物、作品），种子包与任务消息同步改。
