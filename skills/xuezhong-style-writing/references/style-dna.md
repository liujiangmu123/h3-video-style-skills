# 雪中悍刀行写法 · Style DNA

> 提炼自 `..\..\..\视频分析\04_风格解构.md`（读数 `分析素材\text_stats.md`、`rhythm_probe.md`）。章号指原著章节；数字描述原书，不是成片目标。只学写法，不用原著人物与原句。

## THE FORMULA（主配方，置顶）

世情 / 天气长句铺场（回扣物露一次）→ 两人对白带一个笑点 → 65–75% 一次静后落高潮（台词或动作）→ 回一句日常 → 最后 3–5 句 ≤10 字 → 最后一句 = 标题。

## 哲学（证据版）

| # | 相信 | 所以 | 证据 |
|---|---|---|---|
| P1 | 人的分量在离场时才称得出来 | 高潮写"走"不写"赢" | 17 老黄走、21 剑九黄、293 李淳罡、402 温华折剑、482 徐骁转身、954 袁左宗离去 |
| P2 | 大事要小东西来扛 | 便宜旧物前给一次、章末再给一次 | 黄酒坛（21）、木剑（402）、镯子（505）、红狐皮帽（482） |
| P3 | 要人哭先让人笑 | 高潮前放滑稽；情绪写动作 | 17 第 77 段"傻乎乎地跑路了"→ 第 78 段"剑九。"；叙述"笑"37.85 vs"伤心"0.09 / 万字 |
| P4 | 最重的话最短 | 章末段变短、单句成段 | 段长 164 → 28 字；短段最后 10% 占 15.4%，前 80% 为 0 |
| P5 | 说书人可以站出来说一句，但不下断言 | 插"其实"、俚语；叙述不问不喊 | "其实"2.75、"似乎"2.48 / 万字；叙述问号 1.11 vs 对白 8.27 / 千字 |
| P6 | 名字是承诺，最后兑现 | 章题留到章末 | 章题最后一次出现位置 p50 96.7%；15.6% 的章到最后 10% 才第一次说出 |

一句话：先笑着把一个人写活，再用一句最短的话送他走；分量压在一件小东西和一个留到最后才说出口的名字上。

## 三层表

| 维度 | 本质 | 作者默认 | 每期自由 |
|---|---|---|---|
| 旁白 | 说书人评一句；情绪写动作；最重的话最短 | 文白混搭程度、"只是 / 不过"口癖、换称呼 | 俚语、笑点 |
| 选题 | 有人要走 + 有一件小物；只写古代 | 江湖 / 军伍 / 市井 / 父子师徒 | 具体人和事 |
| 结构 | 漏斗长 → 短；高潮 65–75%；标题最后兑现 | 首尾同构（系列可做） | 开头三种选哪种 |
| 考据 | 官职、地名、数字写实 | 借真实朝代制度 | 用哪个朝代 |
| 画面（③ 配） | 回扣物可拍；一场一种强调色 | 雪、酒、剑、马（可换算盘、豆腐、梆子） | 物件、地点、季节 |
| 节奏 / 声音（③ 配） | 越往后镜头越短；高潮前一次静、结尾短句间留白 | 风声、马蹄 | 镜头数、sfx |

## 反例修正（规则的真实强度）

- 段长单调变短：中位规律，开书铺世界的章例外；视频版严格执行。
- 结尾短句：末段 ≤20 字只占 42.1% → "最重的章才用短句收"；视频一期就是最重的一章。
- 叙述问号 1.11 / 千字，规则写"≤1"不写"从不"。
- 章题原样出现只 29.7% → "用了就放最后"。
- 297《斩旗斥剑来》是打脸非离场 → 打脸爽点属作者默认另一类，原创拿不到 IP 爽感，本线不主打。

## 爆点（与风格分开）

前 3 秒：世情句或家常比喻 + 回扣物在画面里，不提问。揭示：65–75%，前面一次静。记忆点：最后一句 ≤10 字 = 标题。热度风险：原著名场面二创热度来自 IP，原创只能靠一句能转发的末句。
