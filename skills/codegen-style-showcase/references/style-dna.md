# 代码生成视频 · 15 种风格 · Style DNA

> 提炼自 `..\..\..\视频分析\04_风格解构.md`（V01 Opus 5.5 十五种风格盘点，约 179 s）。拆的是**格式**；15 个风格块各自能否用 H3 做见 `风格量产\01_风格块与引擎分工.md`。

## THE FORMULA（主配方，置顶）

标题给数目和门槛 → [说明卡先亮（编号 · 名称 · 三行 · 标签）→ 一个最小单位 → 生长 → 约 63% 一次最大变化 → 落版静住 → 静音 + 一颗点过桥] × N → N 格总览 → 标题回扣 + 三段式金句。

## 哲学（证据版）

| # | 相信 | 所以 | 证据 |
|---|---|---|---|
| P1 | 可比才可信 | 同一外框只换芯 | textpanel 15 张同构；同位编号、同一进度条 |
| P2 | 一种风格只证明一件事 | 一支作品、三行说明、两个技术标签 | 03 报告第 9 节 |
| P3 | 万物从一个点开始 | 从最小单位起；段间一颗点过桥 | 00 清单读法 3；反例 02 方块、07 一句提问、09 一只手指 → 改写为"最小单位" |
| P4 | 成品才算数 | 每段落成字标 / 封面 | 卡片"00:10" |
| P5 | 形式即内容 | 作品名就是技法 | 一笔画、一形万象、万物始于一滴 |
| P6 | 让风格自己配乐 | 每段一首，段间一次静 | 02 报告第 7–8 节 |

一句话：用同一个框装 N 种完全不同的芯，每一种都从一个点长成一个能用的成品，让观众自己去比。

## 硬指标（V01 实测）

段长 10.1–12.6 s（p50 10.8，作品 10 s + 过桥 0.8 s）；最大变化 58–72%（p50 63%，12 号 Synthwave 42% 是例外）；段间 0 硬切（7 次硬切全在段内）；段间短静 −42 ~ −52 dB；每段 2–3 色；说明卡 3 行每行 ≤19 字、0 问号 0 叹号；98% 暗帧；左右每段严格交替；滑动 p50 0.5 s；每种风格自带帧率（01 一拍二、09 12 fps）。

## 格式层

片头 4.5 s（2.5%）一颗火星 → 标题 + 副标题（数目 + 门槛）→ 碎成一颗点；正片 15 × 约 11 s（92.9%）；片尾 8.2 s（4.6%）缩成总览格 → 标题 + 三段式金句。

## 三层表

| 维度 | 本质 | 作者默认 | 每期自由 |
|---|---|---|---|
| 画面 | 同一外框装不同芯；每支落成成品 | 暗底；说明栏 + 作品屏；左右交替；编号色 = 强调色；进度条 | 选哪几种、画什么 |
| 节奏 | 点 → 生长 → 一次最大变化 → 落版静住；段间不硬切 | 每段 10 s；最大变化约 63% | 作品内部怎么动 |
| 文案 | 固定结构说明卡只证一件事；作品名 = 技法 | 三行书面克制；无旁白；技术进标签 | 每行写什么 |
| 声音 | 每段一首像它的音乐；段间一次静 | 无旁白、无单列音效层 | 具体曲子 |
| 选题 | 一组能进同一个框比的东西 | "风格"维度；N = 15 | 哪 N 个 |

## 爆点（与风格分开）

前 3 秒：模型名 + 数目 + 门槛。揭示：每段 63% 一次；全片最大揭示在片尾"全部由代码渲染"。记忆点：编号（"我选 9 号"）。热度大半来自"新模型能力"，随模型迭代过期；能长期用的是格式与风格块。
