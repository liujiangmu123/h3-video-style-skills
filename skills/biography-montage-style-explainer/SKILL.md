# 人物传记档案蒙太奇（biography-montage）

## 主配方（纲，冲突时它赢）

```
① 冷开场 ≈25 s（可选，B 线）：命运感音乐，物证按乐句 3–7 s 换，不报名
② 现在时悬案（A）：一件现在时物证 → "他曾……"反差 → 豪言 → "是的，这话当时看来……"
   → "但仅一年后，他真的……" → 脉冲 1（B，兑现）
③ 揭名：名牌先翻扣 → "第一次知道他真正的名字" → 脉冲 2（B，定格物证快切）→ 名牌翻面露名 → 平台
④ 立意（A）："有些时候……"×1–2 → 系列承诺 → 口令"好。话不多说。再次潜入/回到<地名>。<年份>。"（桌面清空）
⑤ 顺叙生平（A）：时间锚开章 → 一张物证停 3–5 句讲故事 → 每个转折只换一个物件或翻一次名牌
   → 暴力/转折处脉冲 3（B）；信源每 ≈50 s；一件物证要出现两次
⑥ 收（A）：证人惊叹 / 本人一句谦辞 → 画布回到开头构图并转灰，只留那件物证的强调色 → 下集钩
```

变量分配：旁白管信息（结局、信源、时间锚）；剪辑管情绪（脉冲只放在兑现/揭名/暴力）；素材动静管时态（现在密、过去静）。

V01 硬指标：14.7 切/分；镜长 p50 1.8 s、p90 8.5 s；≥8 s 镜占时 52.7 %；脉冲 = 3–7 s 内 8–12 切 + 0–5 次闪白；闪白 11 次全片；黑场 0；旁白 4.6–4.8 字/秒、停顿 p50 0.42 s；结局到名字 115 s；暗底 56 %；切点不卡帧（揭名段贴拍 ±0.16 s）。

H3 目标：A 线 10–12 事件/分，静止句 ≥40 %，`max_still_p50_s` 4.0；每 10 分钟 3–4 个 B 线脉冲，每个 8–12 s、≤4 镜，装配时每镜再切 2–3 刀；闪白走代码层（transitions.md C26）。

完整读数与取舍：`references/style-dna.md`。

## 哲学

一句话：人物是被历史推到台前的谜——先给结局，把名字扣住；用证人和物证一层层拆；情绪交给剪刀，不交给形容词。

1. 观众先被结果抓住才关心过程 → 结局前置、名字后揭。
2. 事实要有人作证 → 信源锚，连"没有证据"也说出来。
3. 命运转折是可见的小事 → 每个转折一个物件；一件物证出现两次。
4. 情绪靠剪辑 → 旁白冷静，脉冲 + 闪白只用在三类内容。
5. 讲故事要让观众看得住 → 一半时间是长平台。

选题门：结局门 / 证据门 / 转折门（≥3 个可视化转折，至少一个物证能出现两次）。

## 三层表

| 维度 | 本质 | 作者默认 | 每期自由 |
|---|---|---|---|
| 画面 | 证据感画面铺满；现在密、过去静 | H3：深色档案桌俯视 + 象牙/炭黑纸 + 单一暗红；收尾转灰 | 具体物证 |
| 节奏 | 脉冲 × 平台，脉冲按内容放 | 每 10 分钟 3–4 脉冲 | 脉冲落点 |
| 转场 | 硬切；闪白只做重音；不用黑场、叠化 | 3 种：原位替换 · 名牌翻面 · C17 转灰 | 闪白次数 |
| 旁白 | 结局前置；信源锚；行为与物件代替心理；证人惊叹 | 江湖腔、"有些时候……"、章节口令 | 金句 |
| 声音 | 旁白下全程垫乐、平；不卡帧 | 命运感音乐 | 曲目 |

## 作者感觉

- 想法：从一次会面或一件现在时物证切入，不从出生讲起。
- 画面：一张物证停很久，不每句换图；不用花字表情包。
- 节奏：兑现和名字出口那一下连切加闪白，其余慢。
- 旁白：会说"据他的狱友回忆""但没有外界证据表明"，不会说"他内心十分挣扎"。
- 声音：命运感音乐，不欢快、不大起大落。

## 产线路线与交付格式

主体 A 线（配音先行时间码）：② 章按 `h3-storyboard-writing` §8 格式，画面守 §0（不画人物 → 物证代人；名字只用大字名牌）。脉冲与冷开场作 B 线插段，按 `h3-prompt-writing` 写 `[Shot N]`，每段 ≤4 镜。转场按 `creative-animation-treatment/references/transitions.md`，本风格只许 §3 原位替换、D05 图形匹配、D33 名牌翻面、C17 同位置转灰、C26 冲击帧（代码层）。

## 自检

- [ ] 结局在前 60 s 内出现；名字在揭名段才出口，之前名牌翻扣
- [ ] 每个硬事实有信源；惊叹出自证人；无心理描写
- [ ] 有 ≥2 个脉冲，紧跟 ≥10 s 平台；静止句 ≥40 %
- [ ] 一件物证出现两次，收尾回到开头构图转灰
- [ ] 画面无人物人脸；底部五分之一空
