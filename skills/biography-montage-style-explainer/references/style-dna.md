# style-dna：biography-montage（人物传记档案蒙太奇）

来源片 V01（10:47，2026-10-02 复量，`视频分析\分析素材\V01\quant_v2.json`）。只存本风格读数、取舍与发明；尺子口径见 `style-foundations`。标"待定"的未经人眼看图，不进常量。

## 0. 主配方（置顶，冲突时它赢）

```
冷开场（歌，按乐句 3–7 s/镜，不报名）
→ 现在时悬案（会面/物证 → "他曾……" → 豪言 → "是的，这话当时看来……" → "但仅一年后，他真的……"）
   → 脉冲 1（兑现）
→ 揭名（"第一次知道他真正的名字" → 名字）→ 脉冲 2（定格物证快切）→ 平台
→ 立意（"有些时候……" ×1–2 → 系列承诺 → "话不多说。再次潜入。<地名>。"）
→ 顺叙生平（时间锚开章 → 家世静帧一波 → ≥20 s 平台；转折给行为与物件；暴力处脉冲 3）
→ 收（证人惊叹 → 本人谦辞 → 去色 + 0 切 → 下集钩）
```

变量分配：旁白管信息，剪辑管情绪，素材动静管时态。

## Part A′ H3 翻译（取舍与发明）

| 原片 | H3 写法 | 等级 |
|---|---|---|
| 档案影像、照片 | 物证代人：信件、证件、名牌、地图、空椅、剪影；深色档案桌俯视 + 象牙/炭黑纸 + 单一暗红 | 发明 |
| 现在动、过去静 | 现在时段事件密（每句 1 事件）；过去段一张物证停 3–5 句（静止句 ≥40 %） | 取舍 |
| 脉冲 | B 线插段 8–12 s、≤4 镜，剪辑时每镜再切 2–3 刀到 0.3–0.7 s | 取舍 |
| 闪白 | 代码层 2 帧白层（transitions.md C26）；或 A 线 D34 光脉冲换态（待测） | 取舍 |
| 揭名 | 大字名牌：先翻扣（背面朝上）→ 脉冲 → 翻面露名 | 发明 |
| 一人多名 | 名牌翻面 = 转折；多名并排、一块变红 = 选中 | 发明 |
| 一件物证出现两次 | 收尾用 C17 回到开头构图，全部转灰，只留那件物证的强调色 | 发明 |
| 去色收尾 | 同上 | 取舍 |
| 卡点 | 不要求帧级；装配贴拍 ±0.15 s | 取舍 |

H3 常量：`target_events_per_min` 10–12；`max_still_p50_s` 4.0；静止句 ≥40 %；转场语法 3 种（原位替换 · 名牌翻面 · C17 转灰）。

## Part B 旁白

句式：时间锚开句；信源锚（"据……回忆""××告诉《纽约时报》""但没有外界证据表明"）；反差对句；"有些时候……"立场句（立意段 ≤2 次）；剧透预告"但仅一年后……真的……"；章节口令"好。话不多说。再次潜入。<地名>。"。
从不：问候；情绪词作旁白主语；心理描写；道德审判。
惊叹交给证人："竟然……这真是不可思议"。

## Part C 作者感觉

会从一次会面切入，不从出生讲；会让一张图停 40 秒；会在兑现和名字出口那一下连切加闪白；会说"但没有外界证据表明"；会挑命运感的歌，不让音乐起伏。
