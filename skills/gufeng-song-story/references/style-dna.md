# 古风歌曲 · 一歌一故事 · Style DNA

> 提炼自 `..\..\..\视频分析\04_风格解构.md`（2026-09-30，含用户纠偏）。ID：V01 西湖视频 / T01 褚禄山图文 / S01《不谓侠》mp3。本线没有单一作者，"作者"指栏目形态；数字是原件读数，不是成片目标。

## THE FORMULA（主配方，置顶）

副歌开场亮结局 → 主歌铺"那时" → 副歌前停一小节 → 副歌翻"现在"同构回扣 → 金句起唱点落揭示帧（唯一强调色）→ 间奏 / 尾奏回到第一帧。屏上是小说文字，跟段落走；只有一首歌。

四元组（每期必写）：出处 × 人 × 回扣物 × 金句。

## 哲学（证据版）

| # | 相信 | 所以 | 证据 |
|---|---|---|---|
| P1 | 歌管情绪，故事管具体 | 画面只演一个人一件事，不图解歌词 | V01 唱斜阳月亮，画面始终同一弹唱场景，0 切；S01 热评第一是听众补的具体侠客（45,063 赞） |
| P2 | 只要最高的一段，最狠的一句先亮 | 副歌开场，标题 = 结局句 | V01 从 01:52 第二遍副歌开唱；S01 0.0 s 起副歌；T01 只摘原章末 16.3% |
| P3 | 旧事重演才有力 | 故事有那时 / 现在两层 | T01 八千 → 四百 → "我们只有八千人" → "再走一趟曳落河" |
| P4 | 停一下再给 | 揭示前一次静；强调只一次 | T01 7 字独段"满场肃穆沉默。"在 97.2%；V01"那一天"停 5.6 s；S01 间奏 86.0–94.86 s |
| P5 | 故事从这首歌里长出来 | 歌名的物 / 歌里的地 / 典故 → 传说史书戏文 | 《西湖》热评前三两条发生在西湖；用户："青花瓷就应该是符合青花瓷的故事" |
| P6 | 好文字自己留人 | 屏上主角是小说文字，雪中笔法 | T01 三张长图 1036 字原文，对白加粗，末两段高亮 |

一句话：让一首歌说情绪，从这首歌里找一段本来就有的旧事，用好文字让一个具体的人把它重走一遍；最高的那段先亮，最狠的那句等一次静再落。

## 选题门

G0 贴歌（说得出来源、找得到底本、古代）· G1 具体（一个人一件可见的事）· G2 金句（有一句能单独当钩子，故事里有画面对上）· G3 回扣（那时 / 现在可同构）· G4 静（有值得停的时刻放进空拍 / 间奏）。

## 三层表（摘要）

| 维度 | 本质 | 作者默认 | 每期自由 |
|---|---|---|---|
| 画面 | 结局落在一个人 / 物；不图解歌词；同构回扣；强调色一次 | 园林水雾入画；冷调低饱和 + 一块绿 | 场景、朝代、主角、回扣物 |
| 节奏 | 跟段落不跟歌行；最高段开场；揭示前停 | 一镜到底、零运镜 | 镜数、静在哪一小节 |
| 屏上字 | 标题 = 末句；歌词不改；冷叙述小说，雪中笔法 | 对白加粗、末两句高亮 | 歌、金句、写哪段 |
| 声音 | 一首歌撑满；静处不塞音效 | 真人弹唱 / 电子古风 | 选哪首截哪段 |
| 选题 | 古风歌 × 从歌里长出的古代故事 | 侠、边关、匠人、离别 | 歌、出处、加工 |

## 爆点（与风格分开）

前 3 秒最高段 + 一眼能读的场景；揭示一个名字 / 数字在 70%；一句可截图的话；结尾不号召。没有 IP 热度，用"有热度的古风歌 + 观众半熟的传说"来补（窑工舍身、萧翼赚兰亭、朱家藏季布）。"歌 × 原创故事对上就会火"仍是假设，待外部实证。
