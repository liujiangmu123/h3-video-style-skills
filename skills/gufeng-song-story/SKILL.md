# 古风歌曲 · 一歌一故事 · 风格 skill

从三件参考读出的栏目形态（V01 西湖弹唱视频、T01 雪中褚禄山图文、S01《不谓侠》mp3，2026-09-30 分析）。这条线**偏写作**：成败在"故事贴不贴这首歌"和"小说字好不好读"。读数与证据在 `references/style-dna.md`，原报告 `..\..\视频分析\04_风格解构.md`。

## 主配方（一切细则为它服务）

> **副歌开场亮结局（0–3 s）→ 主歌铺"那时"（一人一地）→ 副歌前停一小节 → 副歌翻到"现在"，同一构图 / 同一件物回扣"那时" → 金句起唱点落揭示帧（全片唯一一次强调色）→ 尾奏 / 间奏定格回到第一帧。**
> 全程只有这首歌；屏上是一段小说文字，跟歌的段落一段一段出；歌词不上屏（金句可在揭示时上屏一次）。

硬指标：段界在小节线；揭示帧在金句起唱点 −0.25–0 s；揭示前 1 小节静止；强调色 1 次；人物不开口；小说字阅读 ≤3.5 字/秒。
每期必须写得出**四元组**：出处（传说 / 史书 / 戏文）× 人 × 回扣物 × 金句。

## 一、写故事（本线的核心）

### 1. 从歌里找故事（贴歌，G0 门）

按顺序问，答出一个就够：
1. **歌名的物**：《青花瓷》→ 景德镇窑工；《兰亭序》→ 萧翼赚兰亭。
2. **歌里的地**：《西湖》→ 西湖旧事；《烟花易冷》→ 洛阳伽蓝。
3. **歌里的典故 / 人物原型**：《不谓侠》→ 无名侠、朱家藏季布。

然后去找那个地方、那件物本来就有的传说、史书、戏文做底。事实部分（人名、地名、朝代、结局）不改，加工只加在细节和虚构的小人物上，简介写出处。说不出"从这首歌哪里来"的，不做；现代故事、现代职业，不做。

### 2. 故事骨架 = 那时 / 现在两层

- **那时**：一人一地一件事，回扣物露第一次（便宜、旧、拿得住）。
- **现在**：同一个人（或后人）重走一遍，同一件物 / 同一个数字再出现（T01：八千 → 四百 → 又是八千）。
- **揭示**：一个名字、一个数字或一件物的来历，放在约 70%，与歌里最狠的那句对齐；最后一句再说一次。

### 3. 小说怎么写（照 02 线笔法，读 `xuezhong-style-writing`）

- 先笑后走：前半段放一个真笑点，高潮写"走"不写"赢"。
- 越写越短：段长单调变短；最后 3–5 句每句 ≤10 字，单独成段。
- 揭示前一句是旁观者的静（"满场肃穆沉默。"这种 ≤8 字独段）。
- 冷叙述：情绪写动作不写形容词；不解释歌；对白加粗；末两句高亮。
- 标题 = 小说末句，≤20 字。
- 字数：短版约 95 s ≈ 300 字（主推）；长版整首 400–600 字；图文版约 1000 字；抖音版约 150 字只给"那时"一眼就懂的题。

### 4. 小说贴歌（对齐表）

先量歌：BPM、小节线、段落起止、金句起唱点（方法见报告 02 第 10 节）。再填这张表，每行一段小说字：

| 歌段 | 起止 s | 小说段 | 屏上字 | 画面状态 |
|---|---|---|---|---|
| 钩子副歌 | | 结局（不解释） | 1–3 行 | 结局画面 |
| 主歌 | | 那时 · 回扣物露一次 | | 约 2 小节一个状态 |
| 副歌前一小节 | | — | 空 | 静 |
| 副歌 | | 现在 · 同构回扣 | | 1 小节可一切 |
| 金句点 | | 揭示句 | 金句可上屏一次 | 揭示帧 · 强调色 |
| 间奏 / 尾奏 | | 末句 = 标题 | | 回到第一帧 |

检查：每屏 1–3 行、每行 ≤16 字；某屏字数 ÷ 停留秒数 ≤3.5；静的那一小节屏上无字。

## 二、画面与出片（引用通用 skill，不在此复制）

- 本线没有自己的画面语言：默认借望海潮 `cinematic-poem-scroll-video` 的画面（不借它一句一镜的节奏），爱情小品可借唐伯虎 `vintage-woodblock-collage-video`。要发明新画面用 `creative-animation-treatment`（`G:\AI\视频分析\skill\2_动画创意_creative-animation-treatment\`）。
- 产线：B 线多镜头 + 歌先行手写时间码；每段画面写法按 `h3-prompt-writing`（`G:\AI\视频分析\skill\4_H3提示词语法_h3-prompt-writing\`）。若改走逐句中文 → 英文分镜，用 `h3-storyboard-writing`（`G:\AI\视频分析\skill\5_逐句分镜写法_h3-storyboard-writing\`）。
- H3 不画中文：小说字装配时叠（ASS / drawtext），画面底部 1/3 留暗留空。

## 三、红线

不图解歌词名词；人物不开口不对口型；不加解说、不喊关注；不叠第二条音乐；不改歌词一字；揭示不放主歌；不生成可识别真人；受保护 IP 人物情节只学方法；未授权歌不混进成片发布；不写现代；说不出出处不做；史实不乱改。

## 四、写完自检（作者感觉）

1. 说得出故事从这首歌哪里来吗？金句是不是恰好落在揭示上？
2. 小说字单独拿出来读好看吗？越往后越短吗？有没有一句解说？
3. 翻在副歌吗？揭示前停了吗？开场是最高段吗？
4. "现在"用了"那时"的构图或那件物吗？
5. 除了这首歌，还听得到别的音乐吗？
