# 电子智人参与式科普 · 风格 skill（style-explainer）

从电子智人《信息论 · 惊奇之学》（V01，303 s，抖音"Vibe 知识大赏"，2026-10-01 分析）学来的风格。生产线 `h3-director` 写这个风格的每一期时读本技能；方向、选题、任务消息在配对的 `dianzi-series-planner`。跨风格通用的参与式方法（十个装置、无风险参与）在共享技能 `participation-design`，本技能只存这个作者的读数和取舍。

只有一支样片：本质按"换题还在不在、去掉了作者感觉还在不在"两问判过；作者默认是从一支片读出来的，换题时可以带理由偏离。

## 主配方（一切细则为它服务）

> **两个小实验开场 → 每章"让你做 → 画出你的状态 → 亮起来 → 才叫出名字 → 推到生活" → 最安静之后最亮的一次翻转 → 问你自己 → 把开头的空格交给你。**

```
冷开场 ≤25 s：两个同构小实验（一个必中、一个必不中），一个"仪表"量出观众的内心状态，20 秒内说完全片论点
→ 片名（约 8% 处）
→ 4–6 章，每章 35–55 s、单字章名、一个舞台：
     出题 / 实验（留白，画面有等待物）→ 画出观众的状态 → 揭晓（变亮 / 变金）→ 命名 → 推远（日常例子或一段历史）→ 章末判断句埋下一章的问题
→ 两次翻转，最大一次在约 2/3 处，紧跟全片最安静的一刻，用唯一一次满屏彩色兑现
→ 回到观众的生活：一句照到今天 + 一个只有他能答的问题 + 最长留白
→ 开头的实验原样回来："这一次，由你来＿" → 片名收
```

硬指标（V01 实测）：字幕一句一屏 4.9–5.6 s、句间 1.1 s、读速 p50 3.2 字/秒；问号 ≤5 且前两句没有；"你"每 2–3 句一次；彩色面积 p50 <1%；一次只发生一个过程。每期换题、实验材料、例子、章名与舞台；不换的是动作链、命名后置、仪表与回扣物、无风险参与、首尾交还。


## 哲学（作者相信什么）

> **先让你在自己的脑子里发生一次，再告诉你它叫什么；讲什么就让你经历什么；最后把问题交还给你。**

1. **理解要先在观众自己的脑子里发生一次** → 每个概念先让观众做一次（补字、估数、自读、比较），再讲。
2. **名字是给体验贴的标签，不是入口** → 术语、公式、人名、年份一律在体验之后；新术语要么挂在体验上，要么挂在刚学会的术语上。
3. **好问题比答案先到，而且要给时间** → 出题后留白 2.5–10 s，留白时画面有"等待物"；问题要么必中，要么答不出就是答案。
4. **讲什么，就让观众经历什么（形式即内容）** → 每期至少一处让观众身上发生本期讲的那件事。
5. **最日常的东西最有力** → 每章至少一个不用解释的共同经验，放在公式前。
6. **安静和黑暗给思考腾地方，亮起来才是重点** → 近黑画布、无人物；揭晓 = 某处变亮 / 变金；满屏彩色全片最多一次。
7. **科普的终点是观众自己的生活** → 最后两章回到观众今天的生活，把开头的实验交还给他。

证据版与三层表在 `references/style-dna.md` 开头。

## 作者感觉

判断标准：电子智人本人拿到这个新题，会不会就这样做。

| 项 | 他会…… | 他不会…… |
|---|---|---|
| 想法 | 先找"观众能在自己身上经历一次"的入口，再决定讲什么；拿最日常的东西当实验材料；让概念自己表演自己 | 从定义、历史、人物生平开讲；只用图表"说明"一个概念 |
| 画面 | 给观众一个能被操作的对象，并把观众脑子里的状态画出来；用"亮起来"告诉你答案在哪 | 画讲解员、卡通角色、装饰插图；用箭头、红圈、放大镜指重点 |
| 节奏 | 问完就停，停的时候留一个发光的东西陪你等；快的只有过程；最大翻转之前最安静 | 问完马上答；揭晓和命名挤在同一秒；全片匀速 |
| 旁白（屏上文字） | 用第二人称确认你刚做的事（"你一定猜到了""你读懂了"），然后才叫出名字；结尾把开头的空格交还给你 | 说"大家好""今天我们来聊"；先说术语；以"关注我"结尾 |
| 声音 | 让声音就是那个过程（打字、滚动、嘀嗒、噪声），或者干脆静；高潮可以整体变响 | 用 boom / 冲击音标重点；配激昂卡点音乐 |

**作者感觉对照**（每期、每个创新都逐项问）：
- 想法：这一期的切口，观众能不能在自己身上当场经历一次？讲 X 的时候，观众身上有没有发生 X？
- 画面：屏上有没有一个观众在"操作"的对象？观众的内心状态有没有被画出来？答案是不是用"亮起来"给的？
- 节奏：每次出题后有没有留白、留白时有没有等待物？最大翻转之前是不是最安静？
- 旁白：每个术语出现前，观众手里有没有一个能被它命名的体验？有没有"你……"确认观众刚做的事？结尾有没有交还？
- 声音：声音是不是过程本身（或静）？有没有任何一处在用声音"喊重点"？

某项不像他，先改做法，不砍点子；只有点子本身违背哲学才换点子。

## 三层表（摘要；完整表与证据在 `references/style-dna.md` B-0）

| 维度 | 本质 | 作者默认 | 每期自由 |
|---|---|---|---|
| 画面 | 屏上始终有一个被观众操作的对象；观众的内心状态被画成看得见的东西；揭晓 = 某处变亮；无人物表演 | 近黑画布 + 发光微粒；金 / 青 / 红 / 灰四色语义；细线线稿；每章一个舞台；满屏彩色只一次 | 舞台物、仪表的样子、实验材料 |
| 画面节奏 | 出题 → 有等待物的留白 → 揭晓；一次只发生一个过程；最大翻转前最安静 | 每章 35–55 s；游戏慢—快—慢；章间淡变；片名约 14 s | 章数 4–6、各章时长 |
| 旁白（屏上文字） | 第二人称确认观众刚做的事；体验 → 命名；问题必中或"答不出即答案"；结尾交还 | 无旁白、中英双语字幕一句一屏；约 5 s 一句、句间 1.1 s；章节单字标题；章末"A，是 B"判断句；无语气词 | 题材、例子、数字、金句、材料 |
| 声音 | 声音是过程的声音或静，从不喊重点；无讲解人声 | 低调长音铺底；细碎过程音；高潮前一次全静、高潮最响 | 音色、铺底曲 |

## 节奏

画面：一章里慢入（出题 + 留白）→ 快中（过程：游戏 / 计数 / 攻击）→ 慢出（命名 + 推远）；全片留白越往后越长（V01 约 4 → 7 → 6 → 10 → 9 s），全落在结构转折点。字幕：一句一屏、在屏时长几乎与字数无关（≈4.7 + 0.036 × 字数 s），句间 1.1 s；读完至少剩 1/3 时间给想。声画：画面领文字——状态先出、揭晓先发生，字幕约 1 s 后命名；字幕从不描述画面。数字与拍型在 `references/style-dna.md` Part A6 与 `references/beat-templates.md`。

## 旁白写法（屏上文字 = 产线里的"旁白"句）

1. 找两个同构的小实验（一个必中、一个必不中）写冷开场 3 句：实验材料不说明 → "你一定……" → 翻成结论 → 第二个实验 → "这一次，你……。而……，才是 X。"
2. 列 4–6 章，每章一个字做标题；每章 5–7 句：出题 / 实验 1 → 过程 1–2（给规律不给答案）→ 命名 1（之前必须已有体验）→ 推远 1–2（例子或历史，人名年份在这里）→ 章末判断句 1（埋下一章的问题）。
3. 两次翻转，都翻"观众刚建立的判断"或"以为没用的东西"；最大那次放约 2/3 处。
4. 回到生活两句：一句照到观众今天；一个只有他能回答的问题。
5. 收尾：三项排比给三个具体的东西 → 金句 → "这一次，由你来＿"。
6. 句长：13–20 字一句，常由两拍短句组成；全片字数 ≈ 目标秒数 × 2.2（原片字幕密度；配音版按总指导 §4.2 × 3.5 另算）。

句式原文、修辞、从不说的话、≥15 句逐字样例、配音版改写规则在 `references/narration.md`。

## 参与装置节拍（每章、全片各排一次）

装置的通用定义、无风险参与判据、参与阶梯 L0–L8 在共享技能 `participation-design`（引用，不复制）；本风格的取舍与位置：

| 位置 | 参与档 | 装置（participation-design 编号） | 本风格写法 |
|---|---|---|---|
| 0:00–0:03 | L1 预测（必中） | 填空 / 自体实验 | 第一帧就是实验材料（代码层大字），首句字幕晚 ≥2 s 出；必中实验也要让人"不由自主做一件事"，平淡（如两条普通线）就改以必错开场、必中作对照 |
| 0:10–0:20 | L2 预测失败 | 不可填 + 不确定可视化 | 候选滚动不揭晓；仪表拉满；论点句 |
| 每章开头 | L3 出题 | 出题 + 计时留白 | 题后 `<#3#>`–`<#5#>`，画面停在静止发光体上 |
| 每章中段 | L4 跟玩 / L5 自体实验 | 跟玩游戏 / 自体实验 | 前慢后快；跟玩要让观众能预判下一步（不是看别人数）；先让做完再揭穿；必成功 |
| 每章揭晓 | L0→命名 | 命名后置 | 画面先变金，下一句（≈1 s 后）才命名 |
| 约 2/3 | L5/L6 | 翻转 + 全屏枢纽 | 翻"观众刚建立的判断"；前一段最安静 |
| 收尾前 | L7 反省 | 出题 + 最长留白 | `<#6#>`–`<#8#>`，只剩光标（代码层） |
| 最后 | L8 交还（可加复测） | 回扣与交还 | 开场材料原样回来，空格只剩光标；能复测就复测（看见自己变了） |

密度：每 40 s 至少一次 L4 以上；单段"接收"（L0）≤15 s；全片参与模态 ≥2 种（读 / 猜之外再用一种：看、听、动手、比较）。每个出力点过一句：**答不出来，观众会觉得是自己的错吗？**会就改。

## 声音母题（V01 的短板，本线要补）

V01 只有通用长音（06 W8）。每期定一个"你的声音"：观众出力那一刻的音（猜测音 / 投票音 / 被骗音），全片同一个音色出现 ≥3 次，最后一次在交还句；后期铺，H3 不写（H3 只写贴事件的单个 sfx_en）。在 ① 里写一行"声音母题：…"。能做声音实验的题（听两遍、听出差别）优先用耳朵做一次自体实验。

## 屏上文字写法（三层，各归各处）

| 层 | 是什么 | 写在原稿哪里 | 规则 |
|---|---|---|---|
| ① 屏中大字 | 实验材料：残句、乱序句、诗、数字、公式 | ① 代码层清单「大字」 | 不进旁白句；≤6 字最好；首帧可见；揭晓字出现时刻 = 同句 H3 变亮事件 |
| ② 屏下字幕 | 产线的"旁白句" | ② / ④ 句行 | 13–20 字、两拍短句、第二人称确认；一句一个信息点；停顿写句末 `<#秒#>` |
| ③ 标签读数 | 仪表数值、"剩余 N 种"、章节标签、英文行 | ① 代码层清单「读数 / 标签 / 字幕英文」 | 小号衬线 + 宽字距英文大写；手机可读：读数 ≥2.6% 画面高、字幕 ≥3.8%，右缘 12% 不放信息 |

旁白句里不能出现：实验材料原文、画面描述（"你看""如图"）、术语先于体验。实验材料所在的一拍，上一句末加停顿给观众读，下一句直接确认（"你读懂了。"）。

## H3 提示词块（衔接两份通用 skill）

本风格只出三样东西，其余照抄通用规则：
1. **风格块**：`references/style-dna.md` A′2 原样用，改的只是 visual_prefix 里"本期舞台物"一句；节奏目标三项必须覆盖（6.0 / 0.04 / 9.0）。
2. **中文画面**：写稿时守 `h3-storyboard-writing` §0；本风格专有：静止句比例约 40–55%（深海是三分之一）、等待物写成静止发光体、揭晓写"瞬间变成暖金色"、过程只写承载物状态并给终点。
3. **英文拍**（建期后，§1–7）：动词与反例按下表；整段提示词由 `h3_timecode` 拼，字段名、顺序按 `h3-prompt-writing` base 模式（`integrated_multimodal_description` → `overall_soundscape` → `non_diegetic_music: N/A`）；脱离工具手写时照 `h3-storyboard-writing` §9。

| 中文画面 | visual_en | sfx_en |
|---|---|---|
| 一条金色细横线瞬间亮起 | `a thin warm-gold horizontal line instantly appears in the upper-middle band, every other element remains exactly unchanged` | `one faint soft tick` |
| 某物瞬间变成暖金色（揭晓） | `the <element from before> instantly turns warm gold` | `a low soft thud` |
| 光脉冲换态 | `the whole canvas instantly brightens one step and settles back; when it settles, <新状态>` | `a soft airy swell` |
| 一半变暗红（排除） | `the left half of the cyan number line instantly turns muted dark red` | `a dry short click` |
| 过程（给终点） | `a cyan line extends from left to right, finishing by <until>` | `a short faint slide` |

不写：flash / glow / flicker / pulse / twinkle、镜头运动、人物、字幕条、`<d>`。手写示例（单段 10 s，段 1）：

```
integrated_multimodal_description: <visual_prefix> <motion_rule> At 00:00.500 a thin warm-gold horizontal line instantly appears in the upper-middle band, then the canvas freezes; At 00:05.300 a short warm-gold bar instantly grows to one third of the frame width just below the line, finishing by 00:05.900, then the canvas freezes, and everything holds completely still until the end. No speech, no dialogue, no human voice of any kind; no people or faces appear; no on-screen text other than the labels described.
overall_soundscape: At 00:00.500 one faint soft tick; At 00:05.300 a thin rising tone. Quiet room tone underneath; no voices.
non_diegetic_music: N/A
```

## 代码动画线分支（Remotion，不走 H3）

本风格画面 80% 以上是字、数、细线与仪表——正是 H3 最弱、代码最准的东西。所以有两条线：

| 线 | 什么时候选 | 怎么做 |
|---|---|---|
| H3 A 线（默认，本技能「产线路线」） | 题材要"世界"：群山、烽火、雪、星空、材质铺满的全屏枢纽 | 本文件全部规则；长字交代码层叠 |
| 代码动画线（Remotion） | 题材几乎全是字、数、几何、错觉材料（方向 B 错觉、方向 C 模拟计数）；或要求一字一像素精确 | 同一份原稿（① 代码层清单 + ② 时间轴）直接驱动 Remotion；`→ 视觉` 写成组件状态变化；不写 H3 英文拍、不跑 h3_timecode。H3 产线工具不管这条线；Remotion 的 Node 依赖没装（装要联网），开工前先问用户 |

分支规则：原稿格式两线相同（便于互换）；在 ① 写明 `产线：H3 / 代码 / 混合`；混合 = H3 出背景世界段、Remotion 出前景层并合成。代码动画线的工程、组件、出片经验在风格线 `风格量产\代码动画线\`（本技能不复制其内容；那里如有 `_skill修改建议.md`，经评审后合并进本节）。

## 产线路线：A 线（配音先行时间码线），两个交付版本

依据：原片画面跟字幕读拍走（每句 5.3 s），不跟音乐拍；脚本报的 5 次"硬切"是 2 次整屏换舞台 + 3 次同构图光脉冲换态，镜头基本锁定（唯一横移 2:58–3:04）。所以走 A 线：单镜 `[Shot 1]`、镜头锁死、`h3_timecode` 按配音时间码拼词。

| 版本 | 怎么做 | 用在 |
|---|---|---|
| **字幕版（默认，最像原片）** | 原稿按 A 线写，每句 = 一句屏下字幕；`h3_plan_durations` 照常跑（配音只当时钟）；思考留白写成句末 MiniMax 停顿标记 `<#秒#>`；粗剪 `h3_assemble mode="rough" audio="segment" subtitles="burn"`，交付 `h3_deliver tier="2k" audio="segment" subtitles="burn"`（只留 H3 事件音，旁白 srt 烧成字幕；标记缺陷见下面 ⚠） | 默认 |
| 配音版 | 同一份原稿，装配用 `audio=mix`；句末停顿照留 | 平台要求有声、或用户要配音 |

**拆层**：H3 只出"世界"（暗场、光点、线描群山与烽火、雪、天线、星空、材质铺满）；**会被观众"读"的字和数**——填空句、候选滚动、计数器、仪表读数、乱序句、公式——超过 4 个字或必须一字不差的，交后期代码层叠（ASS / ffmpeg drawtext / Remotion），H3 画面在那里留空；≤4 字的大字标签可以让 H3 画（逐字写进 visual_en）。字幕版的双语英文行是作者默认，产线可只出中文、英文后期加。代码层目前没有承接的 skill，按 `references/style-dna.md` A′3 手工叠（ASS / ffmpeg drawtext 不用装；Remotion 的 Node 依赖没装，要用先问用户）。

留白在配音里的写法：`最少要问几次？<#4#>`（句末，秒数整数或一位小数，≤10）。按字幕版目标在屏 ≈6.4 s / 句（5.3 + 1.1）补停顿：`停顿 ≈ max(0, 6.4 − 字数 ÷ 4.4 − 0.24)`；出题句、反省句再加 2–6 s。

⚠ 2026-10-01 离线核实：配音层现在会剪掉每句首尾静音，句末停顿留不住（段长、时间码、成片里都没有这段留白），标记还会原样进 SRT、烧进字幕。原稿照这样写（它是这个风格的节奏），但修好前**别真跑配音**——问题和建议修法见 `G:\AI\H3动画量产_AI总指导.md` §13 第 10 条。

## 交付格式（原稿怎么写，工具才读得懂）

一期一份 MD：① 选题信息与查证（含**产线：H3 / 代码 / 混合**、本期两个实验、仪表、回扣物、声音母题、"原来如此"一句、翻转、交还句、代码层清单）/ `## ② 长版旁白时间轴` / `## ④ 抖音版旁白时间轴` / ③ H3 提示词块（可选：本期风格块 + 一段手写示例；建期后以 `h3_storyboard` 为准，放在 ④ 之后不影响解析）/ ⑥ 自检。

- 段头 `【第 N 段 | 段名 | 拍型：Px … | 锚点：…】`，拍型用本技能 P1–P11（`references/beat-templates.md`）。
- 句行 `整句 → 视觉：中文画面`；画面该停的写 `→ 视觉：（静止）`；句里只有要念 / 要显示的字，停顿标记写在句末。
- 交代码层的字**不写进句子，也不写进中文画面**（解析器只认一字不差的 `（静止）`，多写一个字就不算静止）：在 ① 里列一张「代码层清单」——`段.句 | 层（大字 / 读数 / 字幕英文） | 内容原文 | 何时出现（同句开口 / 同句 H3 事件时刻） | 何时消失`；H3 那句画面写本句世界里的变化，或 `（静止）`。
- 中文画面写的时候就守 `h3-storyboard-writing` §0（一句一个看得见的变化、长动作写终点、镜头不动、一段 ≤6 个动作、底部五分之一空）；本风格的冲突处理见 `references/style-dna.md` A′。
- 长版原生约 5 分钟（V01 298 s）；产线长版建议 150–240 s（4 章）、抖音版 55–70 s（冷开场 + 1 章 + 交还）。抖音版必须单独闭环：两个实验 → 一章 → 回扣交还。

## 创新档怎么执行（允许的偏离）

- A：按主配方直走。
- B 母题创新：全片贯穿一个装置（同一个仪表 / 同一句填空 / 同一个舞台物），数字不动；母题由任务消息带来。
- C 形式即内容：调 `creative-animation-treatment` 整片模式，把哲学和三层表本质当不可打破的规则交给它；只接受改每期自由、作者默认最多偏离 1–2 条的方案。参与装置的选择按 `participation-design`。

B、C 写完都过作者感觉对照。允许的偏离（每条一行：偏离哪条作者默认 | 改成什么 | 什么题材用 | 出处期号）：
- 近黑画布 | 米白纸面 + 墨线 | 题材本身是纸、书法、印刷 | 研发线 ⑤ 变体卡 V2 未立，暂作期级
