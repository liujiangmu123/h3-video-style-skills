# 电子智人参与式科普 · Style DNA

> 读数来源：V01《信息论 · 惊奇之学》（303 s，正片 298 s，2026-10-01 分析）。数字描述原片，不是成片目标；翻成 H3 的写法在 Part A′。hex 只作证据，不是常量。

## THE FORMULA（主配方，置顶）

两个小实验开场 → 每章"让你做 → 画出你的状态 → 亮起来 → 才叫出名字 → 推到生活" → 最安静之后最亮的一次翻转 → 问你自己 → 把开头的空格交给你。各环节执行标准在下文，每节标题写明服务配方哪一环；与配方冲突时配方赢。

### 三层表（全表）

| 维度 | 本质 | 作者默认 | 每期自由 |
|---|---|---|---|
| 画面 | ①屏上始终有一个被观众操作的对象（空格、数轴、句子、仪表）②观众的内心状态被画成看得见的东西（候选、剩余数、仪表）③揭晓 = 某处变亮 / 变金 ④无人物表演 | 近黑 + 发光微粒；金 / 青 / 红 / 灰四色语义；细线 + 轻外发光；中文衬线 + 英文斜体；每章一个舞台；满屏彩色一次；左上章节标签 | 舞台物、仪表外观、实验材料、主图形 |
| 画面节奏 | ①出题 → 有等待物的留白 → 揭晓 ②一次只发生一个过程 ③最大翻转前最安静 | 每章 35–55 s；游戏慢—快—慢；章间淡变；整屏重构只用于换舞台；光脉冲换态做揭晓标点；片名约 14 s | 章数、各章时长、过程段长度 |
| 旁白（屏上文字） | ①第二人称确认观众刚做的事 ②体验 → 命名 ③题必中或答不出即答案 ④结尾交还观众 | 无旁白、中英双语字幕一句一屏；~5.3 s 一句、句间 1.1 s；单字章名；章末"A，是 B"判断句；书面干净、无语气词；比喻一章 ≤1 | 题材、例子、数字、金句 |
| 声音 | ①声音是过程或静，从不喊重点 ②无讲解人声 | 低调长音铺底不卡拍；打字 / 滚动 / 嘀嗒 / 噪声过程音；最大翻转前一次全静、翻转时整体最响 | 音色、铺底曲 |

两问判例：无旁白——换题还在；加上不抢答的第二人称旁白作者感觉仍在 → 作者默认。术语后置——去掉就成普通讲解片 → 本质。近黑——换米白底只要揭晓仍是"变亮 / 变色"、仍有大留白，作者感觉大体在 → 作者默认。

## A0 通用尺子取舍（尺子本体在 `style-foundations`）

| 尺子 | 采纳 | 改造 | 拒绝 |
|---|---|---|---|
| 构图 | 中心 + 大留白；明度分层；字幕安全区 | 引导线 → 光点沿线滑动 | 三分法 |
| 配色 | 色彩泛滥作高潮（一次） | 单强调色 → 四色语义 | 60-30-10 |
| 画布 | 近黑 | 颗粒 → 稀疏发光微粒 | 亮底、纸纹 |
| 运动 | 缓入缓出；节奏时序；舞台演出；渐进揭示；共享元素过渡；反馈 | 弧线只一处；跟随 = 光点拖尾 | 预备、挤压拉伸、次要动作、夸张（高潮一次例外） |
| 文案 | 一句一信息点；反差悬念；中段原来如此；结尾金句 | 钩子 → 填空实验；口语 → 书面干净 | 开头提问；先定义；名人开场；行动号召；语气词 |
| 声音 | 音效对位过程 | 配乐 → 长音铺底不卡拍 | 冲击音；人声 |

拒绝与补偿：拒绝旁白 → 第二人称字幕；拒绝问句钩子 → 发光的空格；拒绝冲击音 / 箭头 → 变亮变金；拒绝人物 → 主角是被操作的字和点；拒绝"关注我" → 交还空格。

## Part A 执行标准

### A1 画布（服务：安静给思考 / "亮起来"可读）
近黑 100%，带极淡深蓝暗角；暗像素（亮度 <0.08）常态 0.92–0.98；稀疏发光微粒从 0:00 就在；没有环境光，一切自发光（金字外发光、光点拖尾、烽火光晕）。纯黑白帧 66%。

### A2 色彩（服务：揭晓 = 变金）
彩色面积 p50 0.004 / p90 0.043；同屏色相 p50 1 / p90 3。语义：金 = 信息 / 答案 / 值得的（空格、候选、693、烽火、"绿"字、弧顶光点）；青 = 结构 / 通道 / 还没有信息（仪表零点、横线、刻度、群山、旅行者 1 号）；暗红 = 排除 / 噪声 / 头条（排除区、红块、红噪框、新闻条）；灰 = 冗余 / 乱码 / 早已知道；白 = 中性陈述。满屏彩色只一次（3:26，彩色像素 0.38，其余时刻 ≤0.04）。证据色（不作常量）：金 #CFB97C / #AB7E48，青 #458DA7，红 #AD2F49，CMB #285695 / #A25D2C。

### A3 构图（服务：一眼知道看哪）
主对象居中偏上（屏中大字在画面高 35–45%），占宽 20–40%；屏下 10–15% 是字幕带；左上 (3%, 3%) 章节标签；同屏元素常态 2–4、最多约 8（3:40 分屏）。

### A4 图形语言（服务：主角是被操作的信息）
细线约 1–2 px @720p，轻外发光；几何 + 线稿；无人物、无卡通形象；真实图像只有满屏电视雪花与宇宙微波背景图。每章一个舞台：数轴（猜）、群山烽火 + 城市剪影（惊）、每字柱 + 乱序句 + 蓝框波形（余）、光点 0/1 流 + 旅行者 + 天线 + CMB（噪）、分屏点阵 + 推荐流卡（义）、熵弧线 + 满山烽火（收）。

### A5 文字（服务：语言层 = 旁白）
三层：①屏中大字（实验材料：诗句、乱序句、693、公式），中文衬线字距加宽，数字公式衬线斜体，约画面高 5–7%（693 约 12%），出现方式：打字机逐字 / 淡入 / 微粒聚合 / 逐字跳位 / 分色 / 换字；②屏下双语字幕，中文衬线约 2.2%、英文斜体约 1.5%，一句一屏、约 0.1 s 渐入渐出；③标签读数，小号衬线 + 宽字距大写英文，约 1.2–1.8%。

### A6 节奏（服务：出题 → 留白 → 揭晓）
- 字幕：38 句；在屏 p25/p50/p75 = 4.90 / 5.30 / 5.58 s（≈ 4.68 + 0.036 × 汉字数）；句间 p50 1.10 / p90 3.36 s；读速 p50 3.2 字/秒；全片 655 字。
- 思考留白：0:02 空格 → "光"约 4 s；0:45 问 → 第 1 问约 7 s；2:41 悬问 → 揭晓约 6 s；3:58 反省问 → 下一句约 10 s；收尾空格前后各约 9–10 s。p50 ≈ 6 s，越往后越长。≥3 s 字幕空白 5 处全在结构转折点。
- 章：冷开场 23 s / 片名 14 s / 各章 37–53 s；章内慢—快—慢；游戏第 1→2 问约 2 s、中段每问约 1 s、末两问约 2 s。
- 高潮 3:24–3:26（正片 68–69%），前面 2:45–2:50 是全片唯一长静音（约 57%）。
- 换态：整屏换舞台 2 次（24.0 片名、212.0 换章）；光脉冲换态 3 次（64.1 693 亮起、97.6 雪已落、166.8 冗余编码闪亮）；章间多为淡出淡入。
- 声画：画面领文字，偏移约 +1 s；字幕不描述画面（例外：乱序句是实验材料，读两遍）。

### A7 声音（服务：形式即内容）
无人声（ASR 0 段）。低调长音铺底（每 5 s RMS −13 ~ −25 dB，谱平坦度近 0），拍速不稳（各 30 s 窗 70–172 BPM，峰比 0.36–0.85）——不卡拍。过程音：打字 tick（0.98–5.39 s 每 0.42 s；14.19–15.49 s 每 0.13 s）、候选滚动连响（每 ~0.09 s）、日子嘀嗒（79.4–86.0 s 每 0.09 s）、噪声段持续白噪（147.9–166.8 s）、光标闪烁节拍（约 0.56 s）。165–170 s −54 dB 静音；205–210 s 全片最响 −12.8 dB。

### A8 结构（服务：整条配方）
冷开场两实验 → 片名 → 6 章（猜 / 惊 / 余 / 噪 / 义 / 惊奇之学）→ 收尾交还 → 片名。回扣物：填空句（0:02 / 0:14 / 3:46 / 4:36）、烽火（1:17 / 4:06）、广播句（1:59 / 2:24）、惊奇仪表（0:06 / 3:52）。两次翻转：冗余（浪费 → 铠甲，2:32）、噪声（垃圾 → 最大的惊奇，3:22）。

## Part A′ 翻成 H3（A 线）

### A′1 原片读数 → 产线写法
| 原片 | 产线 |
|---|---|
| 字幕一句一屏 5.3 s | 配音句 = 字幕句；`h3_plan_durations` 出时钟；句末 `<#秒#>` 补到目标在屏时长；字幕版装配 `audio=segment subtitles=burn` |
| 留白 4–10 s | 出题句 / 反省句末 `<#3#>`–`<#8#>`；同时这句之后一句写（静止）或这一句本身（静止），让画面停在等待物上 |
| 等待物（发光问号、光标、空格微光） | 写成静止的发光块面（"一个金色问号停在数轴上方"），不写闪烁——A 线 motion_rule 要求事件间绝对静止；光标闪烁交代码层 |
| 揭晓 = 变亮 / 变金 | visual_en 写 `instantly turns warm gold` / `instantly lights up`；光脉冲换态写成一个复合事件（"整张画布瞬间亮一档又落回，落回时……已经……"），不写 flash / glow / lamp |
| 过程（候选滚动、二分计数、噪声攻击） | H3 只画承载物的状态变化（数轴一半变暗红、波形变红），过程中的字和数交代码层；一个过程 = 一个带 until 的事件 |
| 镜头横移（旅行者 → 地球） | 不写镜头运动；改成内容整排平移或两段（`10\高级转场研究\02` A 线转译） |
| 满屏彩色一次 | 全屏枢纽三拍：灰白雪花铺满 → 浮出彩色（`the only moment in the film when the whole canvas is in full color`）→ 收缩成椭圆 |
| 过程音 | 打字 / 嘀嗒这类密集过程音 H3 写不准，后期铺；H3 只写贴着事件的单个音效 |

### A′2 风格块（`h3_storyboard action=style`，按期改舞台物，不改骨架）

```json
{
  "visual_prefix": "A 2D-animated minimalist explainer on a near-black canvas with a very faint deep-blue vignette and a sparse field of tiny, dim, perfectly still glowing specks. Everything visible emits its own soft light: thin cyan-white line drawings for structure, and a single warm gold reserved for answers and information. Muted dark red appears only for what is excluded or noisy. There are no people, no faces, no hands, no characters and no mascots. Large areas of the canvas stay empty. The upper-middle band is kept clear wherever later text will be overlaid, the lower fifth of the frame stays completely empty at all times, and the top-right corner stays clear.",
  "motion_rule": "One continuous shot with a perfectly locked camera: no zoom, no pan, no camera drift. Every timed event is a single clean change completed within a quarter second, followed by absolute stillness until the next timed event; only one thing changes at a time. Nothing flickers, pulses, drifts or twinkles between events.",
  "no_voice_en": "No speech, no dialogue, no human voice of any kind; no people or faces appear; no on-screen text other than the labels described.",
  "target_events_per_min": 6.0,
  "target_motion_share": 0.04,
  "max_still_p50_s": 9.0
}
```

节奏目标三项必须覆盖：工具缺省是深海的下限（事件 14 个/分、运动占比 12%），本风格 H3 层大量句子静止、变化在代码层，用缺省会一直报"节奏偏疏"。三个值是按 V01 去掉代码层事件后的估计（H3 层约 6–10 个事件/分），第一期实测后改。

`compensation_s`：默认 +0.2 起步（瞬现 + 锁死）；本风格多"变亮"事件，第一期两段草稿跑 `h3_align` 再定（占 GPU，须用户同意）。

### A′3 代码层分工（H3 出世界，代码出思维）
| 交代码层 | 留给 H3 |
|---|---|
| 填空句与空格、候选滚动、计数器 / 剩余可能、位串、仪表读数、公式、乱序句与红块盖字、换字、双语字幕、章节标签、光标闪烁 | 暗场微粒、线描群山与烽火、城市剪影与雪、光点与横线、天线、星空与探测器线稿、雪花 → 彩色材质、熵弧线下的群山、≤4 字的大字标签 |

做法：H3 画面在叠字处留空（visual_prefix 已写 upper-middle band clear）；按 `timing.json` 的句起止生成 ASS（大字层用 `\an8` 屏中上、字幕层 `\an2` 屏下），揭晓字的出现时刻 = 同句 H3 "变亮"事件的时间码；`ffmpeg -vf ass=` 叠在 768 / 2K 成片上。代码层暂无 skill 承接，第一期手工做并把经验写回本节。

### A′4 与 `h3-storyboard-writing` §0 的冲突处理
- §0"一句一个看得见的变化"：本风格大量句子在 H3 层是 `（静止）`、变化发生在代码层——允许；中文画面只写一字不差的 `（静止）`（解析器的静止判定是整行匹配），代码层内容写进 ① 的「代码层清单」。
- §0"画面文字尽量少"：一致——长字全交代码层。
- §0"镜头不动"：一致。
- 本风格"等待物要发光"与默认"事件间绝对静止"：等待物写成静止的发光体，闪烁交代码层。
