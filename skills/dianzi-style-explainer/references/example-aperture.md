# 示例孔径：V01 代表镜头 8 个

每个写：时码 · 事实（画面上发生了什么）· 含义（观众被期待做什么、转折、停在什么状态）· 可借 / 不可借。事实与含义分开写——动作写对了、意思写错，是这个风格最容易犯的错。

## E1 床前明月＿（0:00–0:13）
- 事实：0:02 黑底中上一行衬线字"床前明月"，后面一条发光金色下划线；0:04.4 字幕出；0:06 空格里落下"光"，下方出现小仪表"惊奇 SURPRISE ≈0 bit"，青点停在最左。
- 含义：观众先在心里补出"光"——必中；屏幕随后确认"你一定猜到了"，再用仪表把"你没有被惊到"量成 0。停在：观众刚刚成功，但成功本身被说成"没带来新东西"。
- 可借：同构的"必中填空 + 仪表量 0"；不可借：这句诗本身（每期换材料）。

## E2 窗外下起了＿（0:14–0:23）
- 事实：打字机逐字"那天夜里，窗外下起了"；空格处竖排候选字（灰 / 火 / 光 / 歌 / 信 / 雨 / 雪……）一直滚，不停；仪表金色拉满"? bits"。
- 含义：观众想补，补不出——**不中正是答案**。全片论点在 0:16 说出。停在：观众悬着，空格没被填（要到结尾才交还）。
- 可借："必不中实验"与第一个实验同构；空格不揭晓。

## E3 二分猜数（0:37–1:04）
- 事实：金色数轴 1–1024；发光问号悬停约 4–6 s；"第 N 问 / 剩余 N 种可能"，被排除的一半变暗红，10 个点逐个变 1/0；问得越来越快；693 亮起带同心圆。
- 含义：观众先估"最少几次"，再跟着玩；加速让他从"想每一步"变成"看见规律"。停在：答案亮起、名字（比特）还没出现。
- 可借：游戏前慢后快、进度 + 计数 + 结果同屏、答案"亮起来"。

## E4 烽火与广州的雪（1:17–1:59）
- 事实：线描群山烽火台 + 一年 365 天时间条在走；某天烽火点亮（全片第一次大暖光）；读数 0.004 bit → 8.5 bits；约 90.5 s 淡变到城市剪影；97.6 s 整屏一亮、雪已在落；红条"头条 广州下雪了！"；公式在雪中浮出。
- 含义：两个人人有直觉的生活例先，公式后。停在："惊奇 = −log₂p"刚被写出、观众已经知道它是什么意思。
- 可借：例子在公式前；"同构图光脉冲换态"做揭晓标点。

## E5 研表究明（2:06–2:20）
- 事实：乱序句先完整出现（观众顺读）→ 字上下跳位露出顺序乱了 → 归位并灰 / 金分色"猜得到的 = 冗余 / 猜不到的 = 信息"→ 删灰字只剩"研究汉字顺序影响"。
- 含义：观众先读懂、后被告知读的是乱序——"原来如此"长在观众自己身上。停在：观众意识到自己的大脑一直在"补"。
- 可借：先让他做、后揭穿；实验必成功。不可借：照搬这句网络老梗（每期换一个新的自体实验）。

## E6 噪声攻击（2:24–2:39）
- 事实：广播句入蓝框，波形从平滑变红噪，字被红块一个个盖掉，标签"仍然读得懂"，椭圆光环套住；"冗余 = 铠甲"。
- 含义：观众在噪声里照样读懂——用他自己证明冗余的用处。停在：翻转完成（冗余从浪费变铠甲）。

## E7 雪花 → 宇宙微波背景（3:22–3:31）
- 事实：号角天线 + 红噪框 → 鸽子飞过 → 满屏电视雪花 → 雪花里浮出蓝橙斑块 → 收缩成中央椭圆全天图（全片唯一满屏彩色），全片最响。
- 含义：观众"想删掉的噪声"变成宇宙最早的惊奇——最大翻转。前面 2:45–2:50 是全片最长静音。
- 可借：最安静 → 最亮最响；全屏枢纽三拍（H3 能做，写法见 style-dna A′1）。

## E8 交还（4:35–4:58）
- 事实："那天夜里，窗外下起了＿"回来，空格里只有闪烁光标，没有候选；字幕"这一次，由你来填。"；片名收。
- 含义：同一个画面，意思从"你猜不到"变成"轮到你写"。观众从被测者变成出题人。
- 可借：首尾同一画面换义；把动作留给观众。

## 判定边界
- 只写"文字出现、候选滚动"而没写"让观众先猜、第二次猜不到"——**动作对、意思错**，重写。
- 写成"讲解员说出答案"——违反本质（第二人称确认观众行为、体验先于命名）。
- 揭晓用箭头 / 红圈 / 放大——违反"揭晓 = 变亮"。
