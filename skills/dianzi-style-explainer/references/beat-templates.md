# 拍型与章模板

一段（segment）= 一次 H3 生成 = 一个画面状态的变化过程，8–15 s。拍型写在段头 `拍型：Px …`。下面的"H3 事件"是这一段里 H3 画面要发生的变化，"代码层"写进 ① 代码层清单。

| 拍型 | 名称 | 句数 | H3 事件 | 代码层 | V01 例 |
|---|---|---|---|---|---|
| P1 | 填空实验 | 2–3 | 0–1（舞台微光出现） | 残句 + 发光空格；揭晓字落下；仪表 | 0:00–0:13 |
| P2 | 不可填实验 | 1–2 | 0–1 | 残句 + 候选滚动不停；仪表拉满 | 0:14–0:23 |
| P3 | 片名 | 0–1 | 1（光点沿线滑开 / 微粒聚合的承载物） | 片名字 + 副题 | 0:24–0:37 |
| P4 | 出题 + 留白 | 2 | 1（舞台出现）+ 等待物（静止发光体） | 题面数字、规则 | 0:37–0:52 |
| P5 | 跟玩过程 | 2–3 | 1–2（承载物分区变色、收缩，给 until） | 计数器、剩余可能、位串、问句 | 0:52–1:04 |
| P6 | 揭晓 + 命名 | 2 | 1（光脉冲换态 / 变金） | 答案数字、公式、命名卡 | 1:04–1:17 |
| P7 | 自体实验 | 2–3 | 0–1 | 乱序句 / 被盖的句子 / 对照句；分色；红块 | 2:06–2:39 |
| P8 | 生活推远 | 2 | 1（场景物出现：烽火点亮、雪落、卡片） | 读数（p → bits） | 1:17–1:59 |
| P9 | 全屏翻转 | 2–3 | 2–3（全屏枢纽：铺满 → 彩色浮出 → 收缩） | 名称标签 | 3:22–3:31 |
| P10 | 反省留白 | 1 | 0（静止发光体） | 光标 | 3:58–4:09 |
| P11 | 交还收尾 | 2–3 | 0–1 | 开场残句回来，空格只剩光标；片名 | 4:35–4:58 |

（P9–P11 沿用 P 编号续排；段头写 `拍型：P9 全屏翻转`。）

## 章模板（35–55 s，3–4 段）

```
【第 N 段 | <单字章名>·出题 | 拍型：P4 出题 + 留白 | 锚点：<本章舞台>】
<出题句 1：规则或情境>。 → 视觉：<舞台物出现，一句一变化>
<出题句 2：问题，或"读一下这句"><#3#> → 视觉：（静止）

【第 N+1 段 | <章名>·过程 | 拍型：P5 跟玩过程 / P7 自体实验】
<过程句：给规律，不给答案>。 → 视觉：<承载物状态变化，长动作给终点>
<过程句 2>。 → 视觉：（静止）

【第 N+2 段 | <章名>·揭晓 | 拍型：P6 揭晓 + 命名】
<确认句："你……，因为你……"><#1#> → 视觉：<某处变金 / 光脉冲换态>
<命名句："这，就叫 X" / "A，就是 B">。 → 视觉：（静止）

【第 N+3 段 | <章名>·推远 | 拍型：P8 生活推远】
<日常例子或历史（人名年份在这里）>。 → 视觉：<场景物出现>
<章末判断句："A，是 B"，埋下一章问题>。 → 视觉：（静止）
```

## 冷开场节拍（两个实验，≤25 s）

| 拍 | 观众在做什么 | 文字 | H3 | 代码层 |
|---|---|---|---|---|
| 1 | 自己补字（约 2 s 无字幕） | — | 暗场微粒 | 残句 + 金色空格 |
| 2 | 确认 | 你一定猜到了……。 | （静止） | 空格落字；仪表在 0 |
| 3 | 结论 | 所以……几乎没有……。 | （静止） | — |
| 4 | 想补，补不出 | — | （静止） | 第二残句打字机出 + 候选滚动 |
| 5 | 论点 | 这一次，你……。而……，才是 X。 | 一处变金（仪表承载物） | 仪表拉满 |

## 收尾节拍

反省问 + 最长留白（P10）→ 三项排比 + 金句（P8 变体：开场舞台物逐个点亮）→ 交还（P11：开场残句回来，空格只有光标；"这一次，由你来＿"）→ 片名。

## 抖音版（55–70 s）

两个实验（P1 + P2，约 20 s）→ 一章（P4 → P5/P7 → P6，约 30 s）→ 交还（P11，约 10 s）。论点句与交还句必须都在；不放片名长停。

## 段长与留白

段 1 首事件 ≥0.3 s、段 ≥2 首事件 ≥1.217 s（续接重放头）；一段 ≤6 个时间码；两事件相隔 ≥1.2 s。出题句、反省句放在段尾，让留白落在段与段之间的稳定画面上（段尾写 holds still）。
