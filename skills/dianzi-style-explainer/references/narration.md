# 屏上文字写法（本风格的"旁白"）

> V01 没有旁白、没有人声；语言层是屏中大字（实验材料）+ 屏下中英双语字幕（一句一屏）+ 标签读数。产线里"旁白句" = 屏下字幕句。通识尺子见 `style-foundations` 的 narration-rulers；参与装置的通用写法见 `participation-design`。

## 1. 节奏读数（V01）

| 项 | 读数 |
|---|---|
| 句数 / 字数 | 38 句 / 655 汉字；每句 13 / 18 / 20 字（p25/p50/p75），最长 29 |
| 在屏 | 4.90 / 5.30 / 5.58 s；≈ 4.68 + 0.036 × 字数（几乎不随长短变） |
| 读速 | 3.2 字/秒（p25 2.77 / p75 3.76）；全片密度 2.2 字/秒 |
| 句间 | p50 1.10 s / p90 3.36 s；≥3 s 五处，全在结构转折 |
| 首句 | 0:04.4（先给 2 s 让观众对着空格自己补） |
| 覆盖 | 约 67% 时间有字幕 |
| 句群 | 每章 5–7 句：出题 1 → 过程 1–2 → 命名 1 → 推远 1–2 → 章末判断 1 |

## 2. 句法

- 句型：陈述 33 / 38；问号 4 个——出题（0:45 最少要问几次？）、同句自答（1:19 烽火为什么值得点？）、章首悬问（2:41 会不会吞没一切？）、反省（3:58 有多少是你没有料到的？）。**前两句无问号**——冷开场用填空代替提问。无感叹。祈使 2（去找那些你猜不到的——；由你来填）。
- 人称："你" 17 次 / 38 句；"我" 1 次（出题人下场：我心里想了一个数）；无"我们"。
- 三个最常用句式：
  1. 命名："十个'是或否'，就是十个比特。""猜得到的部分，叫作冗余。""压缩文件，就是删掉那些猜得到的部分。"
  2. 翻转："冗余不是浪费，它是意义穿过噪声时的铠甲。""人们想删掉的噪声，竟是最大的惊奇。""好的惊奇，是意外，又懂得。"
  3. 用观众的经验当证据："你一定猜到了下一个字。""你读懂了，因为你猜得到。""这一次，你猜不到。"
- 拒绝的口头禅：大家好 / 今天我们来聊 / 你知道吗 / 那么 / 没错 / 划重点。"其实"全片 1 次，只在结论句里。

## 3. 修辞

- 比喻少而重：一章 ≤1，喻体是感官物（铠甲、余晖、声音）。
- 翻转两次，翻的都是"观众以为没用的东西"（冗余、噪声）。
- 数字精确且挂在具体东西上：p=364/365 → 0.004 bit（烽火）、≈10 bits（广州的雪）、20 W（旅行者 1 号）、112 bits（诗与乱码）。
- 破折号悬句：只用在后半句是反转或数字时（"发射功率只有二十瓦左右——" / 下一屏 "地球依然能……认出来"）。
- 首尾同句式：0:16"这一次，你猜不到" ↔ 4:43"这一次，由你来填"。

## 4. 结构

- 开场：填空实验 → 确认观众的行为 → 翻成结论 → 第二个同构实验 → 论点。从不用：自我介绍、直接定义、问号开头、名人开场。
- 推进：上一章结论里藏下一章的问题；转场句用"可 / 但"或悬问（"可我们说的话，大部分都在意料之中。""但香农也特意提醒：意义，不在他的公式里。"）。
- 信息顺序：术语全在体验后（比特 1:05、香农 1:10、熵 1:44、冗余 2:14、压缩 2:20、信道容量 2:50、宇宙微波背景 3:26、王安石小注 3:46）；不需要的人名不给（1964 两位工程师）。一句一个信息点，两个点就用句号分两拍。
- 收尾：照到生活 → 反省问 + 最长留白 → 三项排比 → 金句 → 交还。无固定口播。
- 章节标题：单字动作 / 状态（猜 / 惊 / 余 / 噪 / 义），最后一章用片名副题（惊奇之学）。

## 5. 口吻

坐在对面出题的朋友，不急。表演性极低：全片唯一的情绪字是 3:22 的"竟"。可信度靠年份、机构、原话引语、精确读数、"据说"。第二人称确认观众行为是本质；无语气词、低表演是作者默认。

## 7. 从不说的话

1. 不说"大家好""今天我们来聊""欢迎来到"。
2. 不在体验之前说术语、公式、人名、年份。
3. 不描述画面（"你看""如图""这条线代表"）；例外：实验材料可以字幕再读一遍。
4. 不在出题后立刻给答案（≥2.5 s）。
5. 不用感叹号、不用"太神奇了 / 震惊"；全片情绪字最多一个。
6. 不用"我们"；"我"只在出题时。
7. 不说"关注 / 点赞 / 下期再见"。
8. 不问考试题（有对错、答错丢脸）。
9. 同一句不放两个新概念。
10. 不给不需要的人名。

## 8. 写稿公式

1. 找核心现象，问：观众能不能当场在自己身上经历一次？找两个同构小实验（一个必中、一个必不中）。
2. 冷开场 3 句（见 SKILL.md「旁白写法」第 1 条）。
3. 4–6 章，单字章名，每章 5–7 句按"出题 → 过程 → 命名 → 推远 → 判断句"。
4. 两次翻转，大的在 2/3。
5. 回到生活 2 句 + 最长留白。
6. 收尾：排比 → 金句 → "这一次，由你来＿"。
7. 检查：每句 ≤26 字；"你" ≥ 句数 / 3；问号 ≤5 且前两句无；无语气词感叹号；每个术语前有体验；每个问题答不出不丢脸。
8. 英文：不是翻译，是同一个实验的英文版（实验材料英文也要成立，如乱序句英文也乱序）。

## 9. 产线写法（A 线）

- 一句字幕 = 一行旁白句；停顿标记写在句末：`最少要问几次？<#4#>`。字幕版目标在屏 ≈6.4 s / 句，停顿 ≈ max(0, 6.4 − 字数 ÷ 4.4 − 0.24)；出题句 +2–4 s，反省句 +4–6 s，交还句 +6–8 s。
- 实验材料（填空句、乱序句、诗句）不作为旁白句，写进 ① 代码层清单；它所在的那一拍，旁白句写"读一下这句。"或直接用下一句确认句，并在上一句末加停顿给观众读。
- 配音版（有声）额外三条：旁白绝不念实验材料（念了实验就没了）；旁白不抢答——答案先在画面 / 代码层出现，旁白后半拍确认；问号句后必须有停顿标记。
- 英文行：字幕版后期叠（代码层），不进旁白句。
- 和深海旁白规则冲突（深海：≤1 问号、冷开场陈述句、5–15 字短句）：本风格按本文件，不套深海。
