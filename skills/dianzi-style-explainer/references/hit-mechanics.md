# 爆点机制（与风格分开建档）

风格规定"长什么样"，这里规定"凭什么留人、凭什么转发"。读数来自 V01。

## 1. 前 3 秒
一个人人都能补完的残缺句子（0:02 床前明月＿）。观众在 1 秒内就"参与成功"一次——最低门槛、最高确定性。紧接着第二个空格制造"补不出来"的落差，16 秒内说出全片论点。没有片头、没有自我介绍、没有问号。

## 2. 揭示时刻（按强度）
1. 2:14 "你读懂了，因为你猜得到"——自体实验的"原来如此"，发生在观众自己身上，全片最强。
2. 3:26 噪声 → 宇宙微波背景——最大翻转 + 唯一满屏彩色 + 全片最响，紧跟最长静音。
3. 0:16 "猜不到的，才是信息"——论点。
4. 1:04 693 亮起——游戏通关。

## 3. 记忆点 / 可转发物
- 可以拿去考朋友的东西：乱序汉字句、"最少问几次"、广州下雪 ≈10 bits。
- 可截图的判断句：冗余是意义穿过噪声时的铠甲；惊奇是世界正在告诉你新东西的声音。
- 文化共鸣：床前明月光、烽火、春风又绿江南岸。

## 4. 收尾与评论区
交还空格（"这一次，由你来填"）+ 反省问（"今天你看到的东西里，有多少是你没有料到的？"）= 两个现成的评论区话题，天然引导互动；没有"关注我"也能产生评论。

## 5. 收藏 / 复看动机
概念被体验过一次，复看时观众会再"做一遍"实验；章节单字标题方便定位。

## 6. 池深
任何"有一个可亲身经历的入口"的知识都能做：概率与统计直觉、视错觉与知觉、记忆与注意、语言直觉、物理直觉、行为经济学经典实验、算法（排序、搜索、压缩）、密码、博弈……池很深。限制只在选题门 G1 / G2：找不到亲身入口的题（纯史实、纯名词、纯结论）不适合。
