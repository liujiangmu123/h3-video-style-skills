# 风格契合判据（TED 演讲 · 技术科普）

通用评级顺序（三否决 → 契合 → 六力 → 定星判定树）见 `h3-research-director` 的 planning-method 第五节；这里只写本风格专有的。

- 基线：风格 skill `ted-style-explainer` 有哲学、主配方、三层表、作者感觉——见风格 skill 对应节，这里不复制。

## 选题门（由哲学导出）

| 门 | 问 | 来自哲学 | 过的例子 | 不过的例子 |
|---|---|---|---|---|
| G1 一句话 | 这场演讲能压成一句"不是 A，而是 B"吗？ | 一场演讲只送一个观点 | 不是输在山顶，是输在沙发上 | 十个观点并列的"未来趋势"演讲 |
| G2 手边 | 观点能落到观众手边的一个时刻、一件物、一个小动作上吗？ | 先让人认出自己；大结果是小决定攒出来的 | 手机、沙发、闹钟、AI 对话框 | 只能落在"政府应该……"上的政策演讲 |
| G3 可核 | 除了讲者自己的故事，有没有一个能联网核实的数字、研究或事实？ | 鸡汤和道理的差别是一个能核的数 | 职业选手得分率（官方赛事数据可查）、人脸识别错误率论文 | 只有个人感悟的演讲 |
| G4 自己说 | 不照搬演讲的故事顺序和原话，用原始资料和我们自己的例子，能讲清吗？ | 讲的人不比你高明 + 版权 | 观点来自研究，演讲只是出处 | 价值全在讲者个人经历的演讲（讲出来就是复述） |

任一道不过 = 明显短板；G4 不过一律不做（合规）。

## 契合题（三层表本质逐条改写，1–5 分）

| 题 | 来自哪条本质 | 问 | 5 分长什么样 | 1–2 分长什么样 |
|---|---|---|---|---|
| F1 物件可演 | 画面：一束光、手边物件、一次只有一件在变 | 观点能不能由 ≤3 件观众手边的东西在舞台上演出来？ | 观点本身就是一件物的状态变化（手机扣下） | 只能靠图表或文字讲 |
| F2 一个动作 | 画面节奏：观点落在一个决定性动作上 | 观点能不能落成一个看得见的动作（扣下、亮起、盖章、站起）？ | 一个动作就是结论 | 只有抽象结构（"演讲的骨架"这类） |
| F3 认出自己 | 旁白：第一句是具体困境 | 第一句能不能是观众认得出的一个时刻或手里的东西？ | 人人有过的一个晚上 / 一个动作 | 观众手边没有的东西（仿生腿） |
| F4 翻转 | 旁白：一句"不是 A 而是 B" | 有没有一句翻转？ | 翻的是观众的默认想法 | 只是"更多 / 更好" |
| F5 可核阶梯 | 考据：证据可核；画面节奏：证据一级一级亮 | 有没有能核的数字 / 研究 / 事实，排得出三级？ | 一组随条件递增的数（49 → 52 → 55） | 一个孤立数字或没有数字 |

五星要求契合每项 ≥4 且均值 ≥4.5。作者默认（暗场追光、木质小人、5 段 150 秒）不进契合题。

## 六力检验问题

本线有旁白，沿用 planning-method 原版问题打分：冲击 / 拥有 / 闭环 / 留存 / 分享 / 形式。力的名字和星级线不改。本线的读法提示：
- 拥有：看完能不能今晚就做那一步？
- 分享：评论区会不会自我表态或 @ 朋友（原图文 8 条评论里 5 条是这样）？
- 形式：同一个母题（时间胶囊、天平）能不能贯穿一个方向？

## 定星

五星 = 契合每项 ≥4 且均值 ≥4.5，六力 ≥4 项满分且无一项 <3，池深高于叙事轴线附近（100–120 以上）；其余按 planning-method 判定树。池深必须有枚举依据（ted.com 话题计数 + 能落成"你的一个动作"的比例），不拍脑袋。

## 专有否决

| 项 | 判定 |
|---|---|
| 任何截图、剪片段、搬运、翻译、配音、逐句解说 TED 内容的做法 | 合规否决（CC BY–NC–ND） |
| 价值全在讲者个人经历的演讲 | G4 不过，否决 |
| 被撤下或涉伪科学、涉具体讲者名誉的演讲 | 合规否决 |
| TED-Ed 动画类（动画是 TED-Ed 的表达） | 合规 + 撞题否决 |
| 医疗、心理、理财只能给"个人建议"才成立的题 | 合规否决；能改成"只讲研究"的降一星保留 |
| AI × 政治 / 军备 / 国界 | 合规否决 |
