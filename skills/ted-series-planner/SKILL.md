# TED 演讲 · 技术科普 · 选题 skill（series-planner）

研发线用：由 `h3-research-director` 第 ④ 步调用。本技能只决定"做什么"（方向、选题、路线），不写旁白、不写提示词（那是风格 skill `ted-style-explainer`）。判断一个题合不合适，用的是风格 skill 的哲学与三层表本质：**一次只送一个观点——先让你在一个具体时刻认出自己，再用一个小决定和一个能核的数字证明它，最后把选择交回你手里；讲的人从不比你高明。**

## 方法

六阶流程、三个一票否决、爆火六力、星级判定树、每期字段、撞题、任务消息骨架、合规红线按 `h3-research-director` 的 planning-method 走；完整实例看 `shenhai-series-planner`。本技能只存这条线专有的判据、红线、数据和台账。

## 三元组

每期必须写得出三样：**一场演讲（讲者 · 场次 · 年份，可在 ted.com 或 TEDx 官方频道查到）× 一个手边的决定性动作（≤3 件观众手边的东西演出来）× 一个能核的事实（原始研究或官方数据，排得出三级证据）**。写不出任何一样的题不进库。

## 方向轴与来源

**叙事单元轴**：一期 = 一场演讲 × 一个观点。池深五星线 ≥100 期（叙事轴口径）。

候选来源：ted.com 话题页（personal growth、technology、AI、psychology、health、education 等，按话题计数估池深）；TEDx Talks 官方 YouTube（很多爆款只在这里）；TEDAI 维也纳 / 旧金山；B 站 / 抖音的 TED 搬运按播放抽样（只当需求证据，不当素材）；非 TED 讲台（诺奖演讲、传奇技术讲座、公版历史演讲）只在授权干净时进来。

## 版权与合规（专有否决，优先于一切评分）

TED、TEDx 视频与文字稿是 CC BY–NC–ND 4.0：
1. 不截图、不剪片段、不转载、不配音、不翻译、不逐句解说原演讲。
2. 不按演讲的故事顺序复述；讲者本人的个人经历一期最多两句；可引讲者一句原话做评论，注明出处。
3. 不生成讲者肖像、不模仿讲者声音。
4. 栏目名、账号名、封面大字不用 "TED"；不说"TED 官方 / 推荐"；不出现 TED 字标、红色圆地毯 + 红色大字的舞台组合。出处卡里写"观点来自 X 在 Y（场次，年份）的演讲"是事实陈述，可以。
5. 证据回到原始研究或官方数据，自己核、自己引；每期出处必写（讲者、标题、场次、年份、官方链接）。
6. 医疗、心理、理财、育儿只讲研究结论、不给个人建议；在世企业家只讲台上说过的话；AI 与政治、军备、国界相关的不做。
7. 灰区（原创视频变现、TED 把"作为另一部作品的基础"算进 ND）：做带货、付费课之前请律师看；平时降风险的做法是证据链以原始研究为主、不只依赖一个讲者的独家经历。

方向05「讲台动画」用公版演讲原话（作者去世满 50 年或政府作品），TED 演讲要改编成动画必须先拿到 TED 媒体授权与讲者同意——拿到之前只按方向01–04 讲观点。
