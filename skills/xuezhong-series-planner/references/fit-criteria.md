# 风格契合判据（雪中笔法古风短篇）

通用评级顺序（三否决 → 契合 → 六力 → 定星判定树）见 `h3-research-director` 的 planning-method 第五节；这里只写本风格专有的。

- 基线：风格 skill `xuezhong-style-writing` 有主配方（SKILL.md 置顶）、哲学 P1–P6、三层表、爆点（`references/style-dna.md`）和作者感觉五问（SKILL.md「写完自检」）；原报告风格线 `视频分析\04_风格解构.md` 第 2、6、7 节。这里不复制。
- 爆点口径（取自 style-dna「爆点」）：前 3 秒是世情句 + 回扣物，不提问；揭示在 65–75%，前面一次静；末句 ≤10 字 = 标题。原创拿不到 IP 热度，只能靠一句能转发的末句。

## 契合题（三层表本质逐条改写，1–5 分）

| 题 | 来自哪条本质 | 问 | 5 分 | 1–2 分 |
|---|---|---|---|---|
| F1 有人要走 | 选题本质（P1） | 故事的重心是不是一个人的离场？ | 整篇都在为一个人的走铺路 | 离场只是背景，重心在奇事或在赢 |
| F2 小物可拍 | 选题本质（P2）+ 画面本质（回扣物可拍） | 那件物便宜、旧、拿得住、H3 拍得出，开头结尾各出现一次？ | 一只碗、一把刀，两次出现意思变了 | 没有物，或物是抽象的 |
| F3 先笑得出 | 旁白本质（情绪写动作）+ P3 | 前半段的笑点能写在动作和物件上吗？ | 一个能单独复述的笑点 | 只能靠台词耍贫，或根本笑不出 |
| F4 一句收得住 | 结构本质（漏斗、标题最后兑现）+ 旁白本质（最重的话最短） | 最后一句 ≤10 字、能当标题、是全篇最短？ | 末句就是标题，单独发出去也让人停 | 要解释才懂 |
| F5 短篇装得下 | 结构本质（一期一个高潮）+ 红线 8 | 1500 字以内讲得完？背景 1–2 句交代得清？ | 一个地方、两三个人、一个晚上 | 要交代门派恩怨、三代人 |
| F6 考据有底 | 考据本质（官职、地名、数字写实） | 借得到一套真实的制度或行当做底吗？ | 驿丞、军令、换防都说得通 | 只能写成架空仙侠 |

F6 是 2026-10-01 补的（三层表"考据"那行本质原来没进契合题）；三个立项方向补分 B01 5、J01 4（门派是虚构的江湖结构）、S01 5，星级不变。五星要求每项 ≥4、均值 ≥4.5。作者默认（雪、酒、剑、马，文白混搭的程度，首尾同构）不进契合题。

三层表里画面、画面节奏、声音三行由研发线 ③ 配，文字侧的本质怎么覆盖：回扣物可拍 → F2；越往后镜头越短 → F4（漏斗）；一场一种强调色、高潮前一次静 → 不是选题能决定的，写稿时按风格 skill 自检第 2、5 问查。

## 六力检验问题（本风格改写）

力的名字和星级线不改：
- 冲击：第一句世情长句 + 回扣物在第一个画面里，3 秒内能不能让人停下？（本风格拒绝开头钩子，冲击只靠首句本身有趣和那件物）
- 拥有：观众身上有没有对应的"走"（送过人、被送过、老了、放下过一件事）？
- 闭环：最后一句（= 标题）是不是回到开头那件物？
- 留存：往来段的笑点和那句"其实"，能不能把人带到 65%？
- 分享：末句单独发出去能不能让人停？评论区会不会补"我也有一个这样的人"？
- 形式：能不能排季（季末回扣季初）、能不能出图文版（3 张长图）？
