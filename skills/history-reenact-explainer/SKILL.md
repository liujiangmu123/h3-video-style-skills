# 历史影视解说 · H3 原创重演

## 主配方（纲）

0 s 名句 / 史书原话 / 反问钩子 → 0–15% 一句反差设定（他原本被怎样看、历史原本怎样） → 15–85% 2–4 个事件节点，每节点一个情绪特写镜头，镜长约 3–5 s → 85–95% 反转或名句兑现 → 最后一个静默孤独或升华镜头配一句短旁白。B 多镜头线：每段 10–15 s，T2VA，按 `h3-prompt-writing` 三字段写。

## 哲学

用一句名句，把一个人物最被误解或最高光的一刻，重新演给已经认识他的人看。选题门：① 有名句 / 名场面 ② 有"被看错→被看清"的人物弧 ③ 结尾能落反转或名句。三门过两门才做。

## 执行标准（目）

- 画面：live-action cinematic 或 2D ink-wash；低调光，暗部占大半，单侧主光，去饱和，仅 1 个强调色（朱红 / 暖钨丝灯）；景别轮换：情绪特写脸 / 对峙双人 / 群像远景；底部 1/5 留字幕。
- 节奏：每段 3 镜左右，切点写 `At 00:0S.SSS`；反转前一段收短镜，末镜 static hold。
- 旁白：解说用 `(S1) says in an off-screen voiceover`，低沉平稳男声；剧中人台词原创，史书原句、古诗文可引；首尾同一名句呼应；排比收束可用；不堆考据数字。
- 声音：台词优先；BGM 只写配器与速度（古琴、低弦、鼓）；反转处允许音乐骤停。
- 发布：角标"AI 生成·架空演绎"，简介注史料出处与虚构段；评论区置顶一个二选一 / 征集问题。

## 版权红线（每期自查）

1. 不用任何影视 / 动漫原片画面、原声、BGM。
2. 提示词不写演员名、剧名；造型按史料原创，不像任何真人。
3. 只用真实历史人物与公有领域文本；剧中虚构角色（许三多、白展堂、罗兰等）的续写或跨剧对话需权利方授权，否则不做。
4. 原剧本台词不复刻。
5. 按《人工智能生成合成内容标识办法》显式标识 AI 生成。

## 作者感觉对照

- 想法：他会挑被误解的人物，不会做剧情梗概。
- 画面：他会切到脸，不会停在空景讲背景。
- 节奏：开口即冲突、尾部急收，不做片头。
- 旁白：一句名句首尾呼应，不讲大段考据。
- 声音：人声顶前，音乐不盖台词。
